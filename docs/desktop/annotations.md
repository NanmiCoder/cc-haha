# 文本标注与引用

Claude 写完一段东西，你想指出「就是这一句有问题」时，不需要把原话再抄一遍。在对话里选中那段文字，工具栏会给你三个动作，其中最常用的是把它变成一条**标注**：选中、写一句说明、攒够几条一起发送。

## 选中文字后的三个动作

在任意一条消息里拖选一段文字，工具栏会出现在选区旁边：

| 动作 | 结果 | 适合什么场景 |
| --- | --- | --- |
| **标注** | 打开一个小浮层，让你给这段文字写一句说明 | 有明确要求，希望 Claude 按你说的改 |
| **添加到对话** | 只把这段引文放进输入框，不写说明 | 只想把它作为上下文带进去 |
| **在侧边聊天中提问** | 在侧边聊天里就这段文字提问，不占用当前会话 | 想先问清楚再决定怎么改 |

## 写一条标注

点「标注」后浮层里会展开一个输入框，上方是刚选中的原文，下方是你要写的话。浮层支持键盘：

- `⌘↵`（Windows 上是 `Ctrl+↵`）保存
- `Esc` 取消，不会留下任何东西

说明不能为空——空说明等于一条普通引用，那种情况直接用「添加到对话」。所以在什么都没写之前，保存按钮是灰的。

## 保存之后

- 消息里那段文字会留下陶土色的标记，末端带一个小圆点徽标，徽标里是这条标注的编号。
- 输入框上方出现对应的 chip，上面同时显示编号、引文和你的说明。
- 标记本身不拦鼠标，你还能选中同一段文字再标注一次。

编号是全局一致的：消息里的徽标、输入框上方的 chip、以及最终发给 Claude 的 `[Annotation N]`，用的是同一个序号。

## 改和删

点消息末尾的编号徽标，或者点输入框上方的 chip，都会打开同一个浮层。已经写过的说明会填好等你改；左下角的「删除标注」把它整条去掉。

## 一起提交

多条标注可以攒着一次发。发送时它们会排成一个独立段落，每条都带引文和你的说明，编号与界面上看到的一致：

````text
Annotated chat context:
[Annotation 1]
Assistant message:
```
问题出在 ChatInput.tsx:917
```
Comment: 顺序反了，引用应该在正文之后
[Annotation 1 end]
````

没有写说明的普通引用仍然走原来的格式，两者互不影响。

## 什么时候标注会消失

标注是待发送的内容，跟着输入框里的引用一起走：

- **发送后被消费**。标记和 chip 一起消失，标注的全文留在发出去的那条消息里，随时可以回看。
- **消息内容变了**。标注记的是这段文字在消息里的位置；如果那条消息后来被改写，位置对不上就不再画标记（chip 不受影响，你写的说明不会丢）。
