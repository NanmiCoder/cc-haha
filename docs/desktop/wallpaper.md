# 桌面壁纸

桌面端支持三种背景来源：静态图片、本地视频、网页壁纸包。三者共用同一套焦点、缩放、模糊和面板透明度设置；动态来源在本机播放，不联网、不上传任何文件。

入口：设置 → 壁纸。

## 功能概览

| 能力 | 静态图片 | 本地视频 | 网页壁纸包 |
|---|---|---|---|
| 背景来源 | 上传 PNG / JPEG / WebP | 选择本地视频文件 | 选择包含 `index.html` 的目录 |
| 播放行为 | 静止 | 循环静音播放 | 包内自行播放动画 |
| 焦点 / 缩放 / 模糊 | 支持 | 支持 | 支持 |
| 面板不透明度 | 支持 | 支持 | 支持 |
| 聚焦播放、失焦暂停 | — | 支持 | 支持（通过消息通知包） |
| 存储位置 | 服务端配置目录 | 仅记录路径，不复制文件 | 仅记录路径，不复制文件 |

设置页顶部的类型选择器随时可以切换。切换类型只会清除当前来源，不会删除已选的视频或壁纸包。

## 静态壁纸

- **选择图片**：支持 PNG、JPEG、WebP。选图后先在渲染层压缩为 JPEG（最长边 2560px、质量 0.85），再上传，避免大图直接写入存储。
- **拖动取景**：直接拖拽预览图决定视觉焦点，也支持方向键微调（Shift 加速）。焦点会实时同步到主界面。
- **画面调节**：缩放 100–300%、模糊 0–40px、面板不透明度 60–100%。数值变更经防抖后保存，拖动滑块不会连续打请求。
- **开关与移除**：可以随时关闭壁纸回到纯主题，或删除已上传的图片。
- **固定覆盖显示**：图片始终按 `cover` 铺满窗口，不提供「覆盖 / 包含 / 拉伸」选项。
- **与动态壁纸共存**：动态来源激活时接管背景，静态图不会抢先绘制；切回静态时自动恢复。

服务端限制：单张图片不超过 8 MB，只接受 PNG / JPEG / WebP；文件以白名单名称 `wallpaper.jpg|png|webp` 存放在配置目录下，先写临时文件再原子替换，并清理其他格式的旧文件。

## 动态壁纸

### 本地视频

选择本地的 mp4、webm 等视频文件后循环静音播放。窗口失焦或最小化时自动暂停，回到前台继续播放。文件不会被复制，配置里只保存绝对路径；如果文件被移动或删除，设置页会提示「视频文件已丢失」。

### 网页壁纸包

选择一个包含 `index.html` 的目录，页面会在沙箱 iframe 中运行。网页包可以自己用 canvas、CSS 动画或 WebGL 实现效果。页面通过消息接收播放状态，可以在窗口失焦时暂停自己的动画：

```js
window.addEventListener('message', (event) => {
  if (event.data?.type === 'cc-wallpaper:state') {
    // event.data.playing === false 时暂停，true 时继续
  }
})
```

修改网页包后，可以在设置页点击「重新加载」让渲染层重新拉取，无需重启应用。

### 播放与安全

- 视频和网页包通过特权协议 `cc-wallpaper://` 提供，支持 HTTP Range 请求，视频可以流式播放和拖动进度。
- 网页包请求会先解码、拒绝 NUL 字节，再经 `path.resolve` 与 `realpath` 双重校验，禁止读取所选目录之外的文件。
- iframe 使用 `sandbox="allow-scripts"`，包内 CSP 设置 `connect-src 'none'`，无法发起网络请求，也无法访问宿主页面。
- 壁纸相关的 IPC 通道只接受主窗口主框架调用。

## 主题与可读性

壁纸只负责背景与面板透明度，不改动任何主题色。文字、代码块、Mermaid 图表全部沿用当前主题的色板，六套主题切换即时生效，不会出现白底白字。

面板通过 `data-wallpaper-surface` 选择器改为半透明底色，透明度由「面板不透明度」控制：数值越低，背景图透出得越多，文字对比度也越低。

## 隐私

- 静态图片保存在你自己的配置目录，通过带鉴权的本地接口读取。
- 动态壁纸完全由主进程读取本地文件，不经过任何网络服务。
- 三种来源都不会上传、外链或以其他方式离开本机。
- 壁纸功能仅在桌面端提供；移动端不读取相关偏好。

## 相关接口

| 方法 | 路径 | 说明 |
|---|---|---|
| GET / PUT | `/api/desktop-ui/preferences/wallpaper` | 读取 / 更新静态壁纸偏好 |
| GET / PUT / DELETE | `/api/desktop-ui/preferences/wallpaper/image` | 读取 / 上传 / 删除静态壁纸图片 |

动态壁纸的配置与来源由桌面端主进程直接管理，存放在 `userData/wallpaper.json`，不经过上述接口。

## 测试覆盖

- 静态壁纸：默认值、字段归一化与越界裁剪、类型与大小校验、旧文件清理、删除后回退。
- 桌面端：图片压缩尺寸、主题变量下发、store 的加载 / 上传 / 调参 / 移除、设置页拖拽取景与开关交互。
- 动态壁纸：配置归一化、来源校验、路径逃逸、Range 解析、协议路由、图层切换与失焦暂停。
