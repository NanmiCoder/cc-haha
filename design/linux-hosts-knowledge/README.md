## 关键决定

- 桌面客户端只支持并验收 Windows 10 和 Windows 11；不为本功能开发或维持 macOS、Linux 桌面客户端兼容。这里的 Linux 指通过 SSH 管理的远端主机，不是客户端运行平台。
- 右上角增加主机图标，打开单例“主机管理”工作台；左边是标签/主机与远程文件，右边是 SSH 终端和文件编辑标签页。
- 在现有“设置”中增加“概念知识”，与“记忆”并列；不把概念条目写入 `CLAUDE.md`。
- 模型选择器前并排放置“主机”“概念”两个按钮，各自支持多选标签；`/hh`、`/ce` 直达对应选择器。首页首轮和已有会话都支持，两类选择同时保留。
- 旁边增加“数据连接”入口，内含数据库和 Redis 多标签选择；增加 `/db`、`/rd`。所有入口共用引用控制器，不复制四套密码库和标签逻辑。
- 主机、概念、凭据及 SSH 连接由 Electron 主进程管理。前端只持有公开资料和引用，发送时通过一次性票据把已解析的上下文交给现有 sidecar。
- 按用户要求，选择主机时默认包含已保存的 SSH 密码和应用登录密码；选择器明确显示该范围，并允许关闭。私钥正文不进入提示词。
- 默认引用保持在当前会话，直到移除；每次发送重新校验所选版本。该默认值是设计假设，尚未收到用户对生效时长的单独答复。
- “移除引用”只停止后续追加，不能删除已经进入模型历史的资料。凭据库加密与模型输入留存是两件事。
- 数据库采用 `mysql2`、`pg`/`pg-cursor`，Redis 采用官方 Node-Redis 基础客户端 `@redis/client`；成熟完整客户端作为交互参考，不整包嵌入。SQL 查询、结构和 Redis 键值浏览按推荐范围设计，数据写入编辑留待后续明确需求。
- 按用户补充，许可证暂不作为本轮选型和设计的阻塞条件；完整客户端未被直接嵌入的原因是技术边界和集成成本。
- 新业务集中在独立的 managed-resources/managedResources/managedContext 模块中；主工程原文件只放必要接线。禁止复制原 composer、修改 SDK 历史格式或借此重构主工程，以降低上游升级冲突。
