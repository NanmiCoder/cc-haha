# Claude Code Haha v0.2.5

This is a hotfix release that temporarily opens up H5 access so token authentication no longer disrupts chat.

## Highlight

- **H5 token authentication temporarily disabled**: H5/LAN access no longer requires an `Authorization` header by default, avoiding chat or startup failures caused by inconsistent token state after upgrading.

## Fixes

- The server no longer enables authentication automatically just because it binds to `0.0.0.0`; authentication is required only when `--auth-required` or `SERVER_AUTH_REQUIRED=1` is passed explicitly.
- Browser H5 startup no longer reads or validates the H5 token, and remote URLs connect via the open access path.
- The settings page temporarily hides the H5 enable toggle, token preview/regenerate and allowed origins configuration, keeping only the public URL setting and copy entry.
- While H5 token authentication is paused, CORS allows browser origins so cross-origin requests no longer get stuck at preflight.

## Verification

- Added and updated server regression tests covering REST, WebSocket and CORS being accessible without a token by default, and explicit authentication opt-in still working.
- Updated desktop H5 startup and settings page tests covering remote H5 URLs no longer requiring a token and the settings page no longer showing token controls.
- Passed `bun run check:server` and `bun run check:desktop`.

## Installation

### macOS

If the app reports "is damaged" or "cannot verify the developer" on first launch, run:

```bash
xattr -cr /Applications/Claude\ Code\ Haha.app
```
