# Claude Code Haha v0.2.4

This is a hotfix release that resolves startup failures for some desktop users after upgrading to `v0.2.3`.

## Highlight

- **Fixed desktop startup failure**: fixed a local service authentication regression introduced by the `v0.2.3` H5/LAN access changes that left the desktop app stuck on `Missing Authorization header` at startup.

## Fixes

- Fixed the Tauri desktop WebView's access to the local `127.0.0.1` control API being misidentified as a remote H5 request after the desktop sidecar bound to a LAN address.
- Kept the H5 remote access token and CORS boundary: only the Tauri WebView controlling the local loopback sidecar is exempt from the H5 token; LAN or public H5 access still requires proper authorization.

## Verification

- Added a server regression test covering that a Tauri WebView origin accessing the local sidecar at startup no longer triggers the H5 token requirement.
- Confirmed that server tests for H5 token, CORS and WebSocket authentication still pass.

## Installation

### macOS

If the app reports "is damaged" or "cannot verify the developer" on first launch, run:

```bash
xattr -cr /Applications/Claude\ Code\ Haha.app
```
