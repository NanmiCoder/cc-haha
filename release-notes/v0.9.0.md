# Claude Code Haha v0.9.0

这是一次以 **全面集成 Antigravity CLI (ACP)** 为核心的重大版本更新：现在你可以在 **cc-haha 桌面端**（以及 H5 与手机端）直接接入本地 Antigravity CLI，无缝使用 cc-haha 原生的 **Composer**、**内置 Browser Use**、Native Swarm、原生 `AskUserQuestion` 交互卡片、斜杠技能菜单与对话中途干预（Mid-turn Steering）等全套工作台能力。同时，本版本还带来内置 Browser Use 浏览器自动化、Gemini / Vertex AI / AWS Bedrock Converse / Azure OpenAI 多协议代理、桌面端 UI 与后台任务输出 Tab 重构、V6C 纯净中性主题对齐、订阅用量监控与实时 token 速率、Android 应用内 OTA 更新，并修复了一批稳定性与性能问题。

## 核心功能

- **全面集成 Antigravity CLI (ACP)，畅享 cc-haha 桌面端原生体验**（#2043，#2048）：
  - **全端接入与原生工作流**：打通服务端、桌面端、H5 与手机端，在 cc-haha 中直接使用原生 **Composer**、**内置 Browser Use**（自动注入 cc-haha Browser Use MCP 桥接）、Native Swarm（支持可靠停止与恢复）以及实时 token 速率流式显示。
  - **原生交互与中途干预**：支持通过 ACP elicitation 弹出原生 `AskUserQuestion` 多题交互卡片，支持在任务执行中途（mid-turn）直接发送指令干预转向；斜杠菜单自动发现 AGY skills 并保留延迟到达的 ACP 命令；支持 Mobile 端空目录自动发现与 Electron SOCKS5 代理握手。
- **内置 Browser Use**（#2050）：
  - **双模式浏览器驱动**：支持 Workspace 内置浏览器与连接系统浏览器，开箱即用执行网页导航、点击、输入、截图与检查等操作。
  - **多会话隔离与交互打磨**：支持按会话隔离 Workspace 浏览器标签页与后台状态同步，按 Tab 隔离人工接管（Takeover）状态防止跨会话串扰；新增消息关联胶囊（per-message pill）、平稳活动卡片、光标轨迹（cursor trail）、Cookie 刷盘，以及 `BrowserActivityCard` 默认折叠 thinking 与 screenshot 快照。
- **多协议代理支持**（#2003）：代理层新增 **Gemini、Google Vertex AI、AWS Bedrock Converse 与 Azure OpenAI** 四大协议支持，统一多模型接入能力。
- **桌面端 UI 重构与 V6C 中性主题**（#2049，#2051）：
  - **工作台交互升级**：重构桌面端布局与 Composer 菜单，新增后台任务输出 Tab；全局搜索支持直接搜索项目名称（#2035）；`AskUserQuestion` 多题卡片支持 `Ctrl+→` 切题与 `Ctrl+Enter` 整卡提交（#2016）；移除 active composer 下方重复的 project/branch footer。
  - **主题与本地化**：对齐桌面端剩余界面、触屏 H5 与手机端的 V6C 纯净中性浅/深色主题；中文界面下将 `Computer Use` 本地化为「操作电脑」。
- **订阅用量监控与实时速率**（#2047）：桌面端新增订阅用量组件、悬浮迷你条（Floating Mini Bar）与 macOS 系统菜单栏监控；整合模型设置中的官方配额展示，支持 Antigravity 对话中途实时流式显示 token 速率并加固用量统计。
- **手机端与 Android OTA 更新**（#2023，#2036，#2037）：新增 Android 应用内 GitHub Release OTA 更新（支持桌面端中继回退下载）；Mobile Composer 支持上下文感知提示词优化，支持查看 Workflow 运行状态与历史记录。

## 修复

- **Agent Teams 与 Goal 状态机**（#1999，#2001）：修复 Agent Teams 完成后画布流未停止及侧边栏转圈卡死的问题；修复停止 Goal 时未清除 active goal 导致 evaluator 报错死循环的问题。
- **Session 与 Trajectory 完整性**（#1998，#2038）：修复省略 `message.role` 的 assistant 消息在 session 恢复时丢失的问题；为所有桌面端 Provider 记录 Trajectory 快照并支持查看 subagents 详情。
- **大仓库性能与 Diff 展示**（#2000，#2028）：限制大仓库文件视图的 status/tree I/O，防止超大仓库下界面卡死；修复 pre-commit diffs 展示并清晰标记部分变更列表（partial change lists）。
- **Provider 与用量准确性**（#2026，#2027）：修复 Bedrock 丢失 stop reasons、output limits 与 JSON schemas 的问题；修复 Vertex publisher 模型解析与 Gemini URL 重定向；修复 Grok 与 DeepSeek 用量/余额显示异常。
- **Android OTA 稳定性**（#2029）：修复 Android APK 下载中断后的断点续传与缓存过期清理逻辑。

## 安装

桌面端请在下方 Assets 中下载对应平台和架构的安装包：

- macOS：`Claude-Code-Haha-0.9.0-macOS-Apple-Silicon.dmg` / `Claude-Code-Haha-0.9.0-macOS-Intel.dmg`
- Windows：`Claude-Code-Haha-0.9.0-Windows-x64-Setup.exe` / `Claude-Code-Haha-0.9.0-Windows-arm64-Setup.exe`
- Linux x64：`Claude-Code-Haha-0.9.0-Linux-x64.AppImage`、`Claude-Code-Haha-0.9.0-Linux-x64.deb` 或 `Claude-Code-Haha-0.9.0-Linux-x64.rpm`
- Linux ARM64：`Claude-Code-Haha-0.9.0-Linux-arm64.AppImage`、`Claude-Code-Haha-0.9.0-Linux-arm64.deb` 或 `Claude-Code-Haha-0.9.0-Linux-arm64.rpm`

名字以 `-update.zip` 结尾的文件和 `latest*.yml` 是应用自动更新用的，不用手动下载。

Windows 安装包默认未签名：运行时若出现 SmartScreen 提示，确认文件来自本仓库的 Release 后，点「更多信息」→「仍要运行」。

手机 App 升级到 **0.1.7**（需要桌面端 v0.9.0 或更新版本）：

- Android：下载 Assets 中的 `cc-haha-mobile-0.1.7-*.apk` 安装，APK 会在移动端构建完成后自动附上；已安装旧版 Android App 也可直接使用应用内 OTA 更新。
- iPhone / iPad：先在 App Store 安装 TestFlight，再打开 [TestFlight 公开链接](https://testflight.apple.com/join/Nd49JrWZ) 加入测试。新构建需要苹果测试审核通过后，公开链接才会更新到 0.1.7。

# Claude Code Haha v0.9.0

This major release centers on **full Antigravity CLI (ACP) integration**: you can now connect your local Antigravity CLI directly inside **cc-haha Desktop** (as well as H5 and mobile) and use native cc-haha capabilities out of the box—including **Composer**, **built-in Browser Use**, Native Swarm, native `AskUserQuestion` cards, slash skill discovery, and mid-turn steering. It also introduces built-in Browser Use automation, Gemini / Vertex AI / AWS Bedrock Converse / Azure OpenAI proxy protocols, a redesigned desktop layout with a background task output tab, V6C pure-neutral theme alignment, a subscription usage widget with live token speed, and Android in-app OTA updates, alongside stability and performance fixes.

## Highlights

- **Full Antigravity CLI (ACP) Integration with Native cc-haha Experience** (#2043, #2048):
  - **Cross-surface ACP & native tools**: integrates local Antigravity CLI across server, desktop, H5, and mobile, giving you native **Composer**, **built-in Browser Use** (with automatic cc-haha Browser Use MCP bridge injection), reliable Native Swarm stop/resume, and live mid-turn token speed streaming.
  - **Native UI & mid-turn steering**: supports native `AskUserQuestion` UI via ACP elicitation, mid-turn steering, AGY skill discovery in slash menus with late ACP command retention, mobile empty-catalog auto-discovery, and Electron SOCKS5 proxy handshake fixes.
- **Built-in Browser Use** (#2050):
  - **Dual browser targets**: drives both the built-in Workspace Browser and connected system browsers out of the box.
  - **Session isolation & polish**: isolates workspace browser tabs and background state per session, scopes engine takeover state per tab, and adds per-message pills, calm activity cards, cursor trails, cookie flushing, and folded thinking/screenshot snapshots in `BrowserActivityCard`.
- **Multi-Protocol Proxy Support** (#2003): adds Gemini, Google Vertex AI, AWS Bedrock Converse, and Azure OpenAI protocols to the proxy layer.
- **Desktop UI Redesign & V6C Neutral Theme** (#2049, #2051):
  - **Workflow & composer polish**: redesigns desktop layout with a background task output tab and polished composer menu, adds project-name search in global search (#2035), `Ctrl+→` / `Ctrl+Enter` navigation on multi-question `AskUserQuestion` cards (#2016), and removes the duplicate project/branch footer under the active composer.
  - **Theme & localization**: aligns remaining desktop surfaces, touch H5, and mobile with the V6C pure-neutral light/dark theme, and localizes Computer Use to 「操作电脑」 in Chinese UI.
- **Subscription Usage Widget & Token Speed** (#2047): adds a desktop usage widget, floating mini bar, and macOS menu bar monitor, consolidates official quotas in model settings, and streams mid-turn Antigravity token speed with hardened usage accounting.
- **Mobile & Android In-App OTA** (#2023, #2036, #2037): adds Android in-app GitHub Release OTA updates with desktop relay fallback, context-aware prompt optimization in mobile composer, and workflow runs/history viewing on mobile.

## Fixes

- **Agent Teams & Goal loops** (#1999, #2001): stops Agent Teams canvas flow and stuck sidebar spinners after completion; clears active goal on stop and prevents evaluator error loops.
- **Session & Trajectory completeness** (#1998, #2038): preserves assistant messages when `message.role` is omitted; records trajectory snapshots for all desktop providers and supports inspecting subagents.
- **Large-repo performance & diffs** (#2000, #2028): bounds status/tree I/O to prevent large-repo file viewer freezes; shows pre-commit diffs and flags partial change lists.
- **Provider & usage accuracy** (#2026, #2027): preserves Bedrock stop reasons, output limits, and JSON schemas; fixes Vertex publisher model resolution and Gemini URL retargeting; fixes Grok/DeepSeek usage display.
- **Android OTA reliability** (#2029): resumes interrupted APK downloads and reconciles cache expiry.
