# Claude Code Haha v0.1.5

This release focuses on desktop stability, compatibility and responsiveness.

Compared with `v0.1.4`, it mainly fixes WebFetch failing with third-party providers, broken `@` file lists, TODOs leaking across sessions, sessions breaking after switching permission mode, and slow time-to-first-token on desktop.

## Main updates

- Improved WebFetch reliability with third-party providers: the desktop app now skips the failure-prone preflight check by default and bundles the HTML-to-Markdown dependency.
- Improved desktop time-to-first-token, reducing the "sent, but the reply takes forever to start" problem with third-party models and proxy chains.
- Fixed TODOs leaking across sessions and completed tasks lingering into the next turn.
- Fixed `@` file references failing to list files in some directories, with clearer error messages.
- Fixed an old CLI process killing the new session after switching permission mode, which caused the session to exit unexpectedly.
- Improved tab dragging, project filtering, the AskUserQuestion flow and tool message rendering.

## Installation

### macOS

If the app reports "is damaged" or "cannot verify the developer" on first launch, run:

```bash
xattr -cr /Applications/Claude\ Code\ Haha.app
```
