# Claude Code Haha v0.6.4

本次以修复 **Agent Teams 用错模型** 为主，另有一批桌面端问题修复。

**建议所有 0.6.3 用户更新**：如果你使用 DeepSeek 等第三方映射模型，0.6.3 的团队成员会以 `claude-opus-4-8` 发起请求，可能被上游路由到最贵的模型并产生额外费用。

## Agent Teams 模型修复

0.6.3 中，没有单独指定模型的团队成员会被硬编码为 Claude Opus 4.8。在 cc-switch DeepSeek 这类映射供应商下，这个第一方模型 ID 会被上游按最贵档位处理（DeepSeek 官方会把它路由到 DeepSeek V4 Pro），而不是你实际选择的 DeepSeek Flash。

- 未指定模型的成员现在**跟随主会话当前使用的模型**，不再回退到硬编码 Opus。
- Agent 页面上的模型别名（如 `opus`）会经过供应商映射解析，在第三方供应商下落到该供应商自己的模型槽位。
- 在 `/config` 中显式固定的成员模型仍然优先，行为不变。

## 其他修复

- **团队成员权限审批**：成员发起的权限请求会转发到主会话的审批弹窗并标明成员名称，不再一直等待无人处理的审批。
- **会话列表加载**：本地索引为空或仍在构建时不再回退到全量扫描 JSONL，打开侧边栏或 Trace 页不会再长时间卡住。
- **窗口拖拽**：恢复侧边栏和工作区顶栏空白区域的窗口拖动。
- **输入框**：上下文用量改为紧凑环形指示，不再挤占输入框；短项目列表不再显示多余的折叠按钮。
- **模型配置**：连通性测试返回的长错误不再把按钮挤成两行。

# Claude Code Haha v0.6.4

This release is centered on a fix for **Agent Teams picking the wrong model**, plus a batch of desktop fixes.

**Everyone on 0.6.3 should update**: with a mapped third-party provider such as DeepSeek, teammates were requested as `claude-opus-4-8`, which the upstream could route to its most expensive model and bill accordingly.

## Agent Teams model fix

In 0.6.3, a teammate with no model of its own was hardcoded to Claude Opus 4.8. Under a mapped provider such as cc-switch DeepSeek, that first-party model ID is treated as the most expensive tier upstream (DeepSeek routes it to DeepSeek V4 Pro), instead of the DeepSeek Flash you actually selected.

- Members without a model now **follow the lead session's current model** instead of falling back to a hardcoded Opus.
- Model aliases on the Agent page (such as `opus`) are resolved through the provider mapping, landing on that provider's own slot rather than a first-party Opus ID.
- A model explicitly pinned in `/config` still wins, unchanged.

## Other fixes

- **Teammate permission prompts**: requests raised by a member are forwarded to the lead session's approval dialog and labeled with the member's name, instead of waiting on an approval nobody could answer.
- **Session list loading**: an empty or still-building local index no longer falls back to scanning every JSONL, so opening the sidebar or the Trace page no longer hangs.
- **Window dragging**: restores window dragging on the sidebar and the empty workspace header strip.
- **Composer**: context usage becomes a compact ring instead of eating the input width, and short project lists no longer show a fold button.
- **Model settings**: long errors from a connection test no longer squash the button into two lines.
