# Claude Code Haha v0.7.1

本次新增 **ChatGPT OAuth Fast 模式**、**普通 SubAgent 并发上限**、**语音听写快捷键** 和 **CSV / TSV 表格预览**，让上下文压缩更快、进度更清楚。同时集中修复长任务卡住窗口、Bash 命令被误杀、会话关闭后进程不退出、回复重复显示和 Windows 升级失败等问题。

## 核心功能

- **ChatGPT OAuth Fast 模式**（#1502）：使用 ChatGPT OAuth 时，可在模型的推理强度面板中开启 Fast 模式；选中后模型选择器会显示 Fast 标记，重新打开会话也会保留选择。提速效果因模型而异，可能增加额度消耗。
- **普通 SubAgent 并发上限**（#1506）：在「设置 → 通用」限制同一会话内普通 SubAgent 的并发数，前台、后台和恢复的子任务共用上限；达到上限时拒绝新启动，已有任务完成后可继续启动。默认不限，留空保存即可恢复不限；设置对运行中的会话生效，无需重启。主 Agent、Agent Teams 和 Workflow 不计入，也不是跨会话的全局配额。
- **语音听写快捷键**（#1510）：应用窗口在前台时，按一下开始录音、再按一下结束，也支持按住说话、松开结束。macOS 默认右 Option，Windows / Linux 默认右 Ctrl；可在「设置 → 语音输入」开关或自定义。录音进入当前或最近聚焦的聊天输入框，在其他文本框、终端、弹窗和输入法组词期间不会触发；组合键不会误开麦克风。
- **CSV / TSV 表格预览**（#1505）：工作区里的 `.csv` 和 `.tsv` 可直接按表格查看，并通过「表格 / 源码」切换回原文，继续使用行评论和选区引用。支持 UTF-8、UTF-16 和 GB18030 解码，保留单元格原始值；回合改动中的 CSV 仍可打开差异审查。
- **更快的上下文压缩与实时进度**（#1500）：压缩摘要减少可重新读取的文件正文，改用路径和必要信息，缩短摘要生成时间。压缩时显示已用时间和已生成的字符数；重试共用次数预算，避免上游失败时多层重试反复发送整段上下文。
- **自动更新开关**（#1482）：在「设置 → 关于」控制是否自动检查和后台下载更新，关闭后仍可手动检查与安装。选择稍后安装后，不再在退出时替你安装。

## 稳定性与性能

- **长任务流式输出不再卡住整个窗口**（#1503，#1480）：减少流式输出时工具列表、会话标签和侧栏的重复计算与渲染，让长会话运行期间的新建会话、切换标签和输入操作更流畅。
- **修复 Bash 命令被误杀**（#1493）：修复进程守护管道与 Bun 文件描述符复用冲突，避免健康命令随机被终止、反复出现空的 `Exit code 1`，以及 Grep 明明有结果却显示「No files found」。
- **减少服务端内存增长与轨迹写入开销**（#1493）：搜索索引复用后台 worker，避免每次写入新建线程；轨迹超过索引窗口后不再每追加一行就重扫整个窗口，减少长会话的内存累积和写入延迟。
- **回收关闭会话的 CLI 与 MCP 进程**（#1501）：桌面、手机和平板不再长期保留无人查看且已空闲会话的连接；只有后台任务的会话也能按上限收尾。Windows 停止 CLI 时一并清理 MCP 子进程树；IM 聊天在无运行任务、无待审批且双向静默 30 分钟后释放连接，下一条消息仍回到原会话。
- **Agent Teams 动画更流畅**（#1504，#1492）：修复团队关系图流动连线的卡顿。

## 修复

- **思考和回复重复显示**（#1478，#1476）：冷加载历史与实时输出合并时，同一段思考或回复不再同时显示实时版本和落盘版本；思考中的空白片段也会保留，保证回读一致。
- **完整回复被误判为流中断**（#1496，#1481）：部分 Anthropic 兼容网关漏掉最后的 `message_stop` 帧时，只要已收到终止原因且所有内容块完整关闭，就正常接受回复；真正截断的内容仍会报错并重试。
- **项目路径大小写导致实时记录丢失**（#1498）：项目目录仅大小写不同时，仍能找到正在运行的会话 transcript。
- **重启后无法批准 Agent Teams 计划**（#1479，#1475）：批准计划时会先启动已断开的队长，启动失败则保留计划供再次审阅，避免只能新建会话重来。
- **Windows 升级被安全软件拦截**（#1495、#1499，#1486）：安装辅助脚本无法写入或运行时，改用进程检查后备路径；从受同类问题影响的旧版本升级时也能继续安装，同时保留真实写入错误和其他卸载失败的诊断。
- **Windows 启动错误更清楚**（#1479、#1495）：Bun 在执行代码前因内存提交失败崩溃时，给出系统内存提交上限的提示并保留原始输出；sidecar 无法执行时显示文件路径和重装建议。
- **轨迹视图可用高度**（#1507）：打开轨迹视图时隐藏聊天输入框，让轨迹占满可用高度。
- **权限下拉菜单超出窗口**（#1477）：设置里的权限菜单会保持在窗口内。
- **AruHub 预设端点**（#1484）：改为通用 Agent 接口地址。
- **Unicode 文件名预览**（#1511）：Windows / Linux 上，文件名看起来相同但 Unicode 编码形式不同时，也能找到工作区文件并预览。
- **只读目录的数据迁移**（#1511）：修复 macOS / Linux 迁移只读目录时发布失败、回滚后暂存目录无法清理的问题。
- **停止后重新压缩**（#1517）：停止任务后再执行 `/compact`，压缩进度和完成结果能正常恢复显示。
- **工作区文件更新遗漏**（#1517）：补偿漏掉的文件监听事件，恢复目录后刷新相关缓存；搜索内容不变时，结果也会随文件更新刷新。
- **并发上限输入校验**（#1517）：保留非法输入供保存时校验，避免被输入控件清空后误保存为「不限」。

# Claude Code Haha v0.7.1

This release adds **Fast mode for ChatGPT OAuth**, **ordinary SubAgent concurrency limits**, **a dictation keyboard shortcut** and **CSV / TSV table previews**, with faster context compaction and visible progress. It also fixes long runs freezing the window, healthy Bash commands being killed, processes surviving closed sessions, duplicate replies and Windows upgrade failures.

## Highlights

- **Fast mode for ChatGPT OAuth** (#1502): enable Fast mode in the model's reasoning-effort panel when using ChatGPT OAuth. The model selector shows a Fast indicator, and reopening the session preserves the choice. Speed gains depend on the model and may consume more quota.
- **Ordinary SubAgent concurrency limits** (#1506): `Settings → General` can limit ordinary subagents within each session. Foreground, background and resumed workers share the limit; new starts are refused at capacity and can proceed after existing work finishes. The default is unlimited, restored by saving an empty value. Changes apply to running sessions without a restart. The main agent, Agent Teams and Workflow are excluded; this is not a global quota across sessions.
- **Dictation keyboard shortcut** (#1510): with the app in front, tap to start recording and tap again to stop, or hold to talk and release to stop. Defaults to right Option on macOS and right Ctrl on Windows / Linux; configure or disable it in `Settings → Voice input`. Dictation targets the focused or last-focused composer and does not trigger in other text fields, terminals, dialogs or during IME composition. Key combinations do not accidentally open the microphone.
- **CSV / TSV table previews** (#1505): open `.csv` and `.tsv` files as tables in the workspace, with a Table / Source switch that keeps line comments and selection references available. UTF-8, UTF-16 and GB18030 are supported, and cell values stay as written. Changed CSV files still open in the turn's diff review.
- **Faster context compaction with progress** (#1500): summaries use file paths and essential information instead of copying file contents that can be read again, reducing generation time. Compaction displays elapsed time and generated characters. A shared retry budget prevents nested retries from repeatedly resending the full context when the upstream fails.
- **Automatic update control** (#1482): `Settings → About` controls automatic checks and background downloads. Manual checks and installation remain available when disabled. Deferring installation no longer causes the update to install when you quit.

## Stability and performance

- **Long streaming runs no longer freeze the whole window** (#1503, #1480): reduces repeated computation and rendering in tool lists, session tabs and the sidebar, keeping new-session creation, tab switching and typing responsive during long runs.
- **Healthy Bash commands no longer killed** (#1493): fixes a conflict between the process guardian pipe and Bun's file-descriptor reuse that caused random command termination, empty `Exit code 1` failures and Grep reporting "No files found" despite matches.
- **Lower server memory growth and trace-writing overhead** (#1493): search indexing reuses a worker instead of creating one per write, and appending past the trace index window no longer rescans the entire window on every line.
- **Closed sessions release CLI and MCP processes** (#1501): desktop, phone and tablet clients release connections for idle sessions no longer being viewed; background-only sessions also reach their cleanup ceiling. Windows CLI shutdown reaps the MCP process tree. IM chats release their connection after 30 quiet minutes with no active turn or pending approval, and the next message reconnects to the same session.
- **Smoother Agent Teams animation** (#1504, #1492): fixes stuttering flow lines in the team graph.

## Fixes

- **Duplicate thinking and replies** (#1478, #1476): merging cold history with live output no longer shows both the streamed and durable copies of the same content. Whitespace-only thinking fragments are preserved for consistent replay.
- **Complete replies mistaken for interrupted streams** (#1496, #1481): an Anthropic-compatible gateway that drops the final `message_stop` frame can still complete a reply when a terminal stop reason was received and all content blocks are closed. Truly truncated content still fails and retries.
- **Project path casing losing the live transcript** (#1498): a project directory that differs only in case still resolves the running session's transcript.
- **Team plans could not be approved after restart** (#1479, #1475): approval starts a disconnected lead first. If startup fails, the plan stays reviewable instead of forcing a new session.
- **Windows upgrades blocked by security software** (#1495, #1499, #1486): when the installer helper cannot be written or executed, setup uses a fallback process check. Upgrades from older installers affected by the same block can continue, while real write errors and other uninstall failures retain their diagnostics.
- **Clearer Windows startup errors** (#1479, #1495): Bun crashes caused by memory-commit failure before code runs include guidance about the system commit limit and preserve the original output. An unexecutable sidecar reports its path and reinstall guidance.
- **Full-height trajectory view** (#1507): hides the chat composer while viewing the trajectory so the view uses all available height.
- **Permission menu outside the window** (#1477): the settings permission menu stays within the window.
- **AruHub preset endpoint** (#1484): points the preset to its general agent endpoint.
- **Unicode filename previews** (#1511): workspace files on Windows / Linux can be found and previewed when visually identical names use different Unicode normalization forms.
- **Migrating read-only directories** (#1511): fixes publication failures when migrating read-only directories on macOS / Linux and staging directories that could not be cleaned up after rollback.
- **Compaction after Stop** (#1517): running `/compact` after stopping a task restores progress and completion updates correctly.
- **Missed workspace file updates** (#1517): reconciles missed watch events and refreshes affected caches when directories are restored. Search results refresh after file updates even when the query stays unchanged.
- **Concurrency limit input validation** (#1517): keeps invalid drafts for validation on save instead of letting the input control clear them and accidentally save an unlimited value.

## Other

- The PR quality gate gains an end-to-end agent lane without real models and improves test discovery, timeouts and artifact diagnostics (#1511).
- The README acknowledgements include the AtomGit mirror in China.
