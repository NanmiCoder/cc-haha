# Claude Code Haha v0.5.1

This is an experience and stability update after `v0.5.0`. It focuses on Provider import, chat content navigation, background task and reconnect reliability, and further tightens local runtime boundaries.

## New & Improved

- One-click import of Claude Code Providers from cc-switch, and fetching the model list from OpenAI-compatible endpoints.
- The model catalog is now cache-first with background refresh, so an unreachable Provider no longer blocks desktop startup.
- Slash commands are grouped by purpose; run location selection, the send button, session tabs and settings sidebar interaction are further simplified.
- URLs and file paths in replies are directly clickable; Shell tool cards show output, and completed conversations show the end time and duration (#1145, #1146, #1149, #1151).
- Added a "Discuss further" entry to AskUserQuestion, and the system display language is detected and remembered automatically (#1121).
- Improved Telegram session restore, Provider / model switching, Skills invocation, permission confirmation and image replies (#1130).
- Linux Releases add x64 / ARM64 RPM packages; the project license is updated to MIT.

## Fixes

- Fixed old CLI messages being replayed again after the desktop app reconnected.
- Fixed background Agent output being empty when Windows cannot create symbolic links, and tool paths being displayed too long (#1018, #1141).
- Fixed project-level MCP Servers disappearing after restart, and IM settings saving empty binding fields (#1126, #1137).
- Fixed image messages appearing out of order, and the OpenAI Responses conversion losing images returned by tools (#1053, #1095).
- Fixed desktop issues such as element selection confirmation not working, slight WebView size jitter, and the pet task panel hitting the macOS menu bar (#1140, #1144).
- Fixed long-session processing performance and several stability issues in CLI partial output and the restore flow (#1100).
- Strengthened the security boundaries for local files, preview, H5 access and remote image requests, while restoring the normal features they affected.

## Installation

Download the installer for your platform and architecture from the Assets at the bottom of this page:

- Windows: `Claude-Code-Haha-0.5.1-win-x64.exe` / `Claude-Code-Haha-0.5.1-win-arm64.exe`
- Linux x64: AppImage, deb or `Claude-Code-Haha-0.5.1-linux-x86_64.rpm`
- Linux ARM64: AppImage, deb or `Claude-Code-Haha-0.5.1-linux-aarch64.rpm`
