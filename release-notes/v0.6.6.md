# Claude Code Haha v0.6.6

本次新增 **引用历史会话** 和 **跨会话协作**（让 Claude 自己开独立会话并行干活），并对会话加载、历史滚动和搜索做了一轮性能改造。

## 核心功能

- **引用之前的对话**：输入 `@` 可以搜索并引用历史会话，例如「参考 @登录方案 的结论，补充退出登录流程」。引用不会把整段历史复制进上下文，Claude 按需读取被引用会话的内容；点击消息里的引用可直接打开那段对话，原会话不会被唤醒。
- **跨会话聊天与控制**：可以让 Claude 新建独立会话并行推进任务，并在会话之间收发消息、等待状态变化、汇报结果（`ListSessions` / `ReadSession` / `CreateSession` / `SendSessionMessage` / `WaitSessions`）。
  - 新会话会出现在会话列表里，可以单独打开继续聊；其他会话发来的内容以带来源标注的普通消息显示，工具卡片上可以一键打开相关会话。
  - 每组协作最多同时运行 3 个工作会话，其余排队；Git 项目里的工作会话使用独立 worktree。

## 性能

- **大会话加载与滚动重做**：历史改为一次字节上限内整体加载、整体挂载，不再分页拼接，消除滚动时的跳动、闪烁和丢行。
- **`@` 搜索不再卡住其他请求**：提及搜索和会话清理由请求线程挪走，中文 `@` 搜索不再让其他接口排队；会话建议改为直接查本地索引。
- **会话索引状态稳定**：索引重建期间不再在本地索引和全量 JSONL 扫描之间来回切换，侧边栏不再反复闪「使用标准历史」。
- **引用会话的读取有界**：读取被引用会话不再把会话列表轮询拖到超时报错。
- **新增接口耗时监控**：慢请求和大响应会记入诊断面板，卡顿可以直接定位到具体调用。

## 修复

- **#1322** 文件树的「添加到对话」和右键键盘菜单恢复可用。
- **#1327** OpenAI 兼容供应商的嵌套缓存命中量不再被上报为 0。
- **#1335** `electron:dev` 下渲染进程的 CORS 预检不再被拒绝。
- **#1339** 已清除的 goal 不会被旧 transcript 重新激活。
- **#1345 / #1352** 后台任务的完成通知会立即推送，任务不再一直显示「运行中」（这两个 issue 中与后台任务无关的部分不在本次修复内）。
- **#1346** 「打开方式」新增 Zed。
- **#1349** auto-dream 中断后可以自动恢复，不再推迟 24 小时。

## 其他

- **AGENTS.md 项目指令**：默认优先读 `CLAUDE.md`，缺失时回退到 `AGENTS.md`，可以在 `/config` 的 Project instructions 里切换。
- **供应商预设可以切换协议**：双协议端点不再被预设地址锁死，协议与地址不匹配时会提示。
- **Grok 4.7**：支持 `grok-4.7` 及快速档，推理强度按官方在线目录解析，不再被静默降级。
- SubAgent / 团队成员的运行卡片会显示实际使用的模型。
- 上下文用量环按已用比例填充（此前一直是空环）；「关于」面板新增企业微信群二维码；新增模型时不再把当前会话的模型写进该供应商的配置。

# Claude Code Haha v0.6.6

This release adds **referencing past conversations** and **cross-session collaboration** (Claude can spawn independent sessions and work in parallel), plus a performance overhaul of session loading, history scrolling and search.

## Highlights

- **Reference a past conversation**: type `@` to search and reference an earlier session, e.g. "follow the conclusion in @login-plan and add the logout flow". The reference does not copy the whole history into context — Claude reads the referenced session on demand — and clicking it opens that conversation without waking it up.
- **Cross-session chat and control**: Claude can create independent sessions to work in parallel, then message them, wait for state changes and report back (`ListSessions` / `ReadSession` / `CreateSession` / `SendSessionMessage` / `WaitSessions`).
  - New sessions show up in the session list and can be opened and continued on their own; deliveries from other sessions appear as ordinary messages labeled with their source, and tool cards link to the sessions they touched.
  - Each collaboration runs at most 3 working sessions at a time; the rest queue. Working sessions in a Git project use an independent worktree.

## Performance

- **Large-session loading and scrolling redone**: history loads in one byte-bounded response and stays mounted as a single array instead of being stitched from pages, so scrolling no longer jumps, flickers or drops rows.
- **`@` search no longer blocks other requests**: mention search and session clearing moved off the request thread, so a CJK `@` query no longer queues every other API call, and session suggestions are read straight from the local index.
- **Stable index state**: while the index reconciles it no longer flips between the local index and a full JSONL scan, so the sidebar stops flashing "using standard history".
- **Bounded reads for referenced sessions**: reading a referenced session no longer starves the session list poll into a timeout.
- **New API timing monitor**: slow requests and large responses are recorded in the diagnostics panel, so stalls can be traced to a specific call.

## Fixes

- **#1322** Restores file-tree "Add to chat" and the keyboard context menu.
- **#1327** Nested OpenAI cache hits are no longer reported as 0.
- **#1335** CORS preflights from the renderer under `electron:dev` are no longer rejected.
- **#1339** A cleared goal is no longer restored from a stale transcript.
- **#1345 / #1352** Background task completion is published immediately instead of being dropped, so tasks stop showing as running (the parts of these issues unrelated to background tasks are not covered by this fix).
- **#1346** Adds Zed to the "open with" menu.
- **#1349** An interrupted auto-dream recovers instead of being postponed by 24 hours.

## Other

- **AGENTS.md project instructions**: `CLAUDE.md` is still preferred, falling back to `AGENTS.md`; switchable under `Project instructions` in `/config`.
- **Provider presets can switch protocol**: a dual-protocol endpoint is no longer locked to the preset URL, and a mismatch is called out.
- **Grok 4.7**: supports `grok-4.7` and its fast variant, with reasoning effort resolved against the live catalog instead of being silently dropped.
- SubAgent and team member run cards show the model that actually served the run.
- The context meter fills by used share (it used to render an empty track); the About panel gains the WeCom group QR; adding a model no longer writes the current session model into that provider's settings.
