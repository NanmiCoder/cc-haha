# Claude Code Haha v0.6.5

本次新增 **OpenCode Go 订阅供应商**、可搜索的 Composer 能力菜单、批准计划时切换执行模型，并修复了大文件会话打不开等一系列性能问题。

## 新功能

- **OpenCode Go 订阅供应商**：填入订阅的 API Key，即可使用 GLM、Kimi、MiniMax、Qwen、Grok、GPT 等模型。不同模型的协议差异由本地代理自动分流，无需手动配置。
- **Composer 能力菜单**：输入框的「+」菜单现在可搜索，Skills、连接器、Agents、工作流、Agent Teams 和 Computer Use 都从这里进入。
- **批准计划时切换执行模型**：在执行计划确认条上直接选模型——同供应商立即切换，跨供应商自动重启并继续执行，不用重新描述需求。
- **上下文用量面板重做**：以剩余窗口为主，速度、缓存命中率、成本并排展示，不再只给一份分类占比。
- **项目选择器**：Composer 的目录选择支持搜索全部项目，并可直接新建项目（使用系统文件夹对话框）。
- **Claude Opus 5**：新增 Opus 5 作为官方默认模型。

## 性能与稳定性

- **大会话可以正常打开了**：subagent 记录不再内联进会话历史，之前 542 MB 的响应降到 40 MB。部分会话此前会直接报 `Unexpected end of JSON input`。
- **历史与 Trace 走本地索引**：打开或轮询 Trace 不再整份读取会话 JSONL，长会话的历史滚动恢复连续，搜索索引不再无上限增长。
- 修复大记录和部分 transcript 无法查看的问题。

## 修复

- **模型选择**：会话侧栏刷新后不再把当前模型回退成旧值。
- **AskUserQuestion**：切换标签或滚动不再丢失已填写的答案；等待回答期间输入框会锁定，避免消息被误认为已经回复。
- **Token 统计**：改为新输入 + 输出，不再把缓存命中算成消耗（此前 270k 窗口的 DeepSeek 会话会被显示成 4000 万 tokens）。
- **新建会话目录**：从项目根目录创建，不再落到过期的 worktree 目录（曾导致 `Branch "main" is already checked out`）。
- **任务停止**：已结束的任务再点停止不再报错，Activity 面板不会一直停在「运行中」。
- **连接器安装**：修复 `enabledPlugins` 残留记录导致后续所有 Skill 安装失败的问题。
- Composer 中的超长连续字符串不再撑破面板宽度。

# Claude Code Haha v0.6.5

This release adds the **OpenCode Go subscription provider**, a searchable composer capability menu, model switching at plan approval, and fixes for a batch of large-session and history performance problems.

## New features

- **OpenCode Go subscription provider**: enter your subscription API key to use GLM, Kimi, MiniMax, Qwen, Grok and GPT models. The local proxy routes each model to the wire format it expects, so no manual setup is needed.
- **Composer capability menu**: the "+" menu is now searchable, and is where Skills, connectors, agents, workflows, Agent Teams and Computer Use are reached.
- **Switch the execution model at plan approval**: pick a model right on the plan approval bar — same provider switches in place, cross-provider restarts the CLI with the new settings and continues, without restating the task.
- **Context usage redone**: the panel now leads with the remaining window and shows speed, cache hit rate and cost side by side.
- **Project picker**: the composer's directory picker searches all projects and can create a new one through the native folder dialog.
- **Claude Opus 5**: added as the official default model.

## Performance and stability

- **Large sessions open again**: subagent transcripts are no longer inlined into session history, dropping a 542 MB response to 40 MB. Some sessions previously failed outright with `Unexpected end of JSON input`.
- **History and traces served from the local index**: opening or polling a trace no longer reads the whole session JSONL, scrolling back through long sessions stays continuous, and the search index no longer grows unbounded.
- Fixed inspection of large records and partial transcripts.

## Fixes

- **Model selection**: a sidebar refresh no longer reverts the model you selected.
- **AskUserQuestion**: switching tabs or scrolling no longer loses answers already entered; the composer locks while a question is pending so a message is not mistaken for an answer.
- **Token accounting**: counts new input + output instead of treating cache hits as spend (a 270k-window DeepSeek session used to read as 40M tokens).
- **New session directory**: sessions are created from the project root instead of a stale worktree (which caused `Branch "main" is already checked out`).
- **Task stop**: stopping an already-finished task no longer errors, and the Activity panel stops showing it as running.
- **Connector installs**: fixed the leftover `enabledPlugins` entry that made every later Skill install fail.
- Very long unbreakable strings in the composer no longer widen past the panel.
