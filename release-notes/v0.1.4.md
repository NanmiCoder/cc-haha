# Claude Code Haha v0.1.4

This release focuses on desktop experience improvements and stability fixes, covering stronger Windows Computer Use support, a better desktop sidebar, a macOS title bar drag fix, and desktop code block rendering fixes.

## Main features

- Improved Computer Use support on Windows:
  - Added Python runtime detection and a bridge interface, completing detection and invocation of `python` / `python3` / `py` on Windows.
  - Added Computer Use pre-authorization settings with persistent management of authorized apps, clipboard read/write and system shortcuts.
  - Improved the desktop Computer Use settings page with dependency status checks, installed app selection and authorization toggles.

- Improved the desktop sidebar collapse experience:
  - The sidebar collapses and expands with a smoother transition, and the main chat area takes over the space more naturally.
  - The collapsed state keeps a clear way to restore it, so you are never left wondering how to expand it again.
  - Keyboard search automatically expands the sidebar when needed before focusing the search box.

## Fixes

- Fixed the empty area on the right side of the macOS window not being draggable once session tabs filled the title bar, restoring title bar dragging.
- Fixed some Markdown code blocks degrading to raw text in packaged desktop builds, improving syntax highlighting reliability.
- Fixed display issues with chat code blocks in cases such as `bash`:
  - Fixed content touching the edges and incorrect padding.
  - Adjusted the default code block line height for a more compact display.
  - Turned off line numbers by default in chat code blocks to reduce visual noise.
- Fixed several display details related to desktop tool output and Markdown code blocks, with added test coverage.

## Installation

### macOS

If the app reports "is damaged" or "cannot verify the developer" on first launch, run:

```bash
xattr -cr /Applications/Claude\ Code\ Haha.app
```
