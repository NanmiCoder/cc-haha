# Claude Code Haha v0.7.5

本次带来 **跨会话模型分工**、**重做后的 Token 用量页** 和 **实验性的精简 Agent 模式**，工作区也支持给 Word、PDF、表格加批注；同时修复 OpenCode Go 的 Gemini 模型不可用、macOS 全屏、缓存命中率统计、Windows 数据迁移权限预检等一批问题。

## 核心功能

- **跨会话模型分工**（#1626，#1628，#1629，#1631）：一个会话可以把任务分给若干子会话，每个子会话单独指定供应商和模型；也可以先看一份方案，再决定要不要启动。分工列表移到了「活动」栏，展开就能看到每个会话用哪个模型、跑到哪一步。已启动的会话也能换模型，可以选「本轮结束后切换」或「立即暂停并切换」，切换没生效前会话照常用原来的模型把当前轮跑完；一次最多修改 8 个已启动会话。
- **Token 用量页重做**（#1612，#1618，#1627）：页面开头直接给出生命周期总量（中文按万/亿、英文按 k/M/B 显示），下面是按模型拆分的 90 天柱状流：每天一根柱子、零基线，模型颜色固定不变，排名变动也不会换色。指针指向某一天就能看到当天总量和每个模型各占多少，点一下会钉出一张当天卡片（含最忙的一天与活跃日均值对比、当天的会话数和工具调用数）。还可以在本地生成竖版、方形或横版的用量分享图，主题跟随设置。
- **精简 Agent 模式（实验性）**（#1613，#1619）：桌面「设置 → 通用」可以选择标准或精简，新建会话在发出第一条消息之前也能临时选。精简模式使用更短的系统提示词，只保留读写文件、搜索、终端等核心工具，连接器（MCP）、子 Agent、智能体团队、计划模式等一律不可用，技能仍可按需调用。模式在会话创建后锁定，想换只能新建聊天。
- **工作区文档批注**（#1608）：Word、PDF 和表格预览里可以直接选中文字或单元格加批注，批注会带上文件、页码或工作表位置、引用内容和你的修改要求一起发到对话里；同一个文件可以攒多条批注再一起发。

## 修复

- **OpenCode Go 的 Gemini 模型不可用**（#1630）：OpenCode Go 把每个模型绑定到一种协议，gemini-* 只在 Google 的 generateContent 接口上提供服务，此前一律落到 chat/completions 并报 400（ModelProtocolUnsupported）。现在按 generateContent 协议代理，请求、回复和分页续传都支持，函数调用的思考签名也能原样回传；桌面模型选择器里也能按协议分组显示。
- **macOS 全屏**（#1606）：主窗口恢复原生全屏，绿色按钮和「视图 → 进入全屏」都走系统全屏（会开独立 Space），不再只是放大窗口；隐藏窗口前会先退出全屏，不再留下黑色桌面。Windows 上按 F11 也能全屏。
- **缓存命中率统计**（#1621）：中转站返回的 usage 里 prompt_tokens 已经算上缓存命中的部分时，不再把命中量重复加一遍，命中率回到正常值。
- **Agent Teams 相关界面**（#1621）：计划弹窗里模型写的长文本不再撑出横向滚动条；很短的消息下方「编辑」按钮不再点不到；队伍还在干活时，会话标签上的运行圆点会亮。
- **Windows 数据迁移**（#1620）：迁移前先在临时目录里试做同样的权限操作，不再等数据全部复制完才发现没法保留权限；失败时能看出是哪个操作、哪个条目失败，且不包含路径和账号信息。
- **项目选择菜单**（#1609）：窗口较矮时，菜单按触发按钮上下的剩余空间限高并在内部滚动，「新建项目」「选择其他文件夹」不再被挤出窗口。
- **IM 设置的「已保存」提示**（#1610）：提示改为由页面状态驱动，离开设置页时定时器会一起清掉，不再留下残留的定时任务。

## 其他

- **桌面宠物的等待徽章**（#1534）：宠物窗口新增一个独立的琥珀色徽章，标出有多少个对话在等你回复（等待输入或待批准），展开后可直接跳到对应会话。

# Claude Code Haha v0.7.5

This release adds **model delegation across sessions**, a **redesigned Token usage page** and an **experimental lean Agent profile**, and lets you annotate Word, PDF and spreadsheet files in the workspace. It also fixes unusable Gemini models on OpenCode Go, macOS fullscreen, cache-hit accounting, Windows data-migration permission preflight and more.

## Highlights

- **Model delegation across sessions** (#1626, #1628, #1629, #1631): a session can hand work to child sessions, each with its own provider and model, or present an editable proposal before anything launches. Delegated sessions now live in the Activity rail, where every row names the model it will run and how far it has got. Running sessions can switch models too — either after the current turn or by pausing immediately — and keep their old model until the switch takes effect. At most eight running sessions can be changed at once.
- **Token usage page redesigned** (#1612, #1618, #1627): the lifetime total now leads the page in your own units (万/亿 for Chinese, k/M/B for English), followed by a 90-day stream split by model. Each day is one zero-based column, and model colors are fixed so a model keeps its color when the ranking changes. Pointing at a day shows its total and every model's share; clicking pins a card with that day's figures against the busiest and average active day, plus its sessions and tool calls. You can also render a portrait, square or wide usage image locally, in the current or any chosen theme.
- **Lean Agent profile (experimental)** (#1613, #1619): pick standard or lean in Settings → General, or temporarily before sending the first message of a new session. The lean profile uses a shorter system prompt and keeps only the core file and terminal tools; connectors (MCP), sub-agents, agent teams and plan mode are unavailable, while skills can still be invoked on demand. The mode is locked once the session exists — switch back by starting a new chat.
- **Workspace document annotations** (#1608): select text in Word and PDF, or cells and ranges in spreadsheets, and attach an annotation. The annotation carries the file, its page or sheet location, the quoted content and your requested change into the chat, and several annotations on one file can be sent together.

## Fixes

- **Gemini models on OpenCode Go** (#1630): OpenCode Go binds each model to one wire protocol and serves Gemini only at Google's generateContent endpoint, so gemini-* models fell through to chat/completions and every request failed with 400 ModelProtocolUnsupported. They are now served over generateContent, including streamed replies and continuations, and the thought signatures of function calls are replayed as-is; the desktop model picker also groups them by protocol.
- **Fullscreen on macOS** (#1606): the main window is fullscreenable again, so the green button and View > Toggle Full Screen use native fullscreen (with its own Space) instead of merely zooming the window, and hiding the window leaves fullscreen first, so no black desktop is left behind. F11 toggles fullscreen on Windows.
- **Cache-hit accounting** (#1621): when a relay reports OpenAI-shaped usage whose prompt_tokens already include the cache hit, the hit count is no longer added a second time, and the hit rate is correct again.
- **Agent Teams surfaces** (#1621): long model-written text in the plan dialog no longer forces a horizontal scrollbar, the edit button under a very short message is reachable again, and the session tab shows a running dot while a team is still working.
- **Windows data migration** (#1620): the same permission operation is now tried on empty probes in a private staging area before any data is copied, so an impossible permission transfer fails early instead of after copying everything. Failures report which operation and entry failed, without paths or account names.
- **Project picker menu** (#1609): in a short window the menu is capped at the room left on the chosen side and scrolls inside, so New project and Choose another folder stay reachable.
- **IM settings "Saved" hint** (#1610): the fade is driven by the save status, and leaving the page clears the timer instead of leaving one behind.

## Other

- **Waiting-session badge for the desktop pet** (#1534): the pet window gains a separate amber badge counting the conversations waiting for you — an input or an approval — and expanding it takes you straight to that session.
