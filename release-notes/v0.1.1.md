# Claude Code Haha v0.1.1
Focused fixes for Windows desktop startup errors and window controls.

## Fixes
- Fixed the minimize / maximize / close buttons not working in the Windows custom title bar.
- Fixed the desktop app failing to start a chat when Git is not installed.
- Improved Windows startup error messages to show the exact failure reason for easier troubleshooting.

## Impact
Windows no longer requires Git to be pre-installed to start and use the app; special tools that depend on a terminal environment now show a friendly message instead of crashing.

## Installation
**macOS**
If the app reports "is damaged" on first launch, run:
```bash
xattr -cr /Applications/Claude\ Code\ Haha.app
```
