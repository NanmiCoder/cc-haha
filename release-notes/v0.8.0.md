# Claude Code Haha v0.8.0

这是一次以 **UI 全面重构** 为核心的大版本更新：桌面端、H5 与手机端整体升级为极简黑白双主题视觉系统（纯白浅色 / 哑光炭黑深色），同步重构应用壳层、侧栏、会话工作流与输入框质感，并全面接入开源 AI 品牌图标库 `@lobehub/icons-static-svg` 统一模型与供应商视觉标识。同时新增 Claude Code 快速模式（`/fast`）、上下文感知提示词优化、输入框上下键历史记录、AskUserQuestion 图片与备注支持、消息内联本地音频播放、Grok Official 上下文窗口对齐与按模型覆盖、第三方供应商网络安全提示词开关，以及手机端屏幕常亮与后台重连稳定性优化，并修复了本地索引扫描风暴、重连丢失文件变更卡、侧栏右键菜单溢出、iOS 嵌套弹窗卡死、Telegram 中途报错残留流等一批问题。手机 App 升级到 0.1.6。

## 核心功能

- **桌面端、H5 与手机端 UI 全面重构**（#1983）：
  - **黑白双主题视觉系统**：将桌面端、H5 与手机端收敛为「纯白浅色」与「哑光炭黑深色」两套高对比极简主题，统一背景层次、细线边框、圆角、阴影与文字层级，并自动将旧版多主题配置（`light`、`paper`、`warm-classic`、`celadon`、`ink-blue`、`neutral-dark`）无损迁移到对应的浅色或深色主题。
  - **壳层、工作流与输入框重塑**：重构应用壳层、顶栏标签、侧栏会话卡片、消息流、审批/提问面板与悬浮输入框细节；同步统一手机端与 H5 的配色、启动页背景与锁屏实时活动外观。
  - **开源 AI 品牌图标**：接入 `@lobehub/icons-static-svg`，在模型选择器、供应商配置、会话卡片与分享图等界面统一使用开源标准 AI 品牌图标。
- **Claude Code 快速模式（`/fast`）**（#1970）：支持 `/fast [on|off]` 命令、设置页开关及输入框快速模式切换，覆盖受支持的 Claude 模型；支持组织/额度状态同步与冷却提示，并在切换到不支持的模型时自动降级提醒。
- **输入框上下文感知提示词优化**（#1965）：输入框新增一键提示词优化，复用当前会话上下文与提示词缓存对草稿进行润色与补全，帮助更清晰地表达需求。
- **输入框历史记录上下键导航**（#1957）：光标位于输入框首行/末行时按 `↑` / `↓` 键可快速翻阅当前会话及同项目历史提示词（与 CLI 的 `history.jsonl` 共享）。
- **AskUserQuestion 图片与备注增强**（#1961，#1972）：问答卡片支持粘贴、选择和拖拽图片附件与缩略图预览，支持补充选项备注，并与聊天交接流程更顺畅地衔接。
- **消息内联本地音频播放**（#1969）：聊天消息和工作区 Markdown 预览中引用的本地音频文件（`.wav`、`.mp3`、`.m4a`、`.ogg`、`.flac`、`.aac`、`.opus`）以及 base64 音频链接可直接渲染为内联音频播放器。
- **Grok Official 上下文窗口与按模型覆盖**（#1977）：对齐 Grok Official 各模型真实上下文窗口（如 Grok 4.5–4.7 为 500K、`grok-build-0.1` 为 256K、Grok 4.20/4.3 为 1M），并在登录态下支持按模型手动覆盖上下文上限。
- **第三方供应商网络安全提示词开关**（#1971）：设置中新增开关，允许在使用第三方供应商时关闭内置的 Anthropic 网络安全系统提示与文件读取提醒，同时保持 Claude Official 官方 OAuth 账号行为完全一致。
- **手机端屏幕常亮与后台重连优化**（#1974，#1980）：手机设置 → 外观新增「屏幕常亮」开关（支持 Android、iOS 与 H5 浏览器 Wake Lock），切入后台自动释放、回前台自动恢复；后台期间暂停心跳与重连循环，回到前台立即恢复会话并重置退避时间。

## 修复

- **本地索引扫描风暴与子 Agent 读取饥饿**（#1978，#1982）：修复发送提示词和子 Agent 写入时触发本地索引全量扫描风暴的问题，显著改善后台阻塞与子 Agent 查看响应速度。
- **重连后保留回合文件变更卡**（#1973）：后台任务、历史回填或空闲重连期间保持已展开的回合文件变更卡、滚动位置与输入草稿；运行中或检查点未就绪时防止误撤销。
- **侧栏会话右键菜单防溢出**（#1976，#1981）：右键点击侧栏底部的会话时，菜单自动按视口边界收敛与翻转，不再被窗口底部裁剪。
- **iOS 问答与弹窗嵌套冲突**（#1939，#1966）：将手机端问答页的「先讨论一下」与各类面板改为内联浮层，修复 iOS（React Native Fabric）下双层原生 Modal 同时关闭导致的界面卡死问题。
- **Telegram 中途报错流状态残留**（#1944，#1962）：修复 Telegram 通道在回合中途报错后未清空累积流式文本与定时器、导致下一轮回复混入上一轮残余内容的问题。
- **Prompt Hook 超时双重叠加**（#1935，#1967）：修复带显式超时的 Prompt Hook（如 `/goal`）被外层与内层计时器重复包裹导致超时被误判为静默取消的问题。
- **跨会话投递状态可见性**（#1968）：`ListSessions` 与 `SendSessionMessage` 暴露更清晰的会话状态与投递回执，便于区分排队中、已投递和已消费。

# Claude Code Haha v0.8.0

This major release centers on a **full UI redesign** across desktop, H5, and mobile: a crisp dual monochrome visual system (pure white light and matte charcoal dark), reconstructed app shell, sidebar, conversation stream, and composer craftsmanship, plus unified open-source AI brand icons via `@lobehub/icons-static-svg`. It also introduces Claude Code fast mode (`/fast`), context-aware prompt optimization, Up/Down prompt history navigation, image attachments and notes in `AskUserQuestion`, inline local audio playback, aligned Grok Official context windows with per-model overrides, an opt-out for third-party cyber-risk prompts, and mobile keep-awake with stabilized background reconnect, alongside fixes for local index sweep storms, turn change card persistence across reconnect, clipped sidebar context menus, iOS nested modals, Telegram residual stream state, prompt hook timeouts, and cross-session delivery state. The phone app updates to 0.1.6.

## Highlights

- **Desktop, H5 & mobile UI redesign** (#1983):
  - **Dual monochrome theme system**: consolidates desktop, H5, and mobile onto two canonical high-contrast grounds — pure white light (`white`) and matte charcoal dark (`dark`) — with refined borders, elevation, and typography. Existing legacy theme preferences (`light`, `paper`, `warm-classic`, `celadon`, `ink-blue`, `neutral-dark`) migrate forward automatically without resetting your light/dark choice.
  - **Refreshed shell, worklog, and composer**: rebuilds the app shell, tab bar, sidebar session cards, transcript stream, approval/question surfaces, and composer card, alongside aligned mobile/H5 palettes, splash screens, and iOS Live Activity styling.
  - **Open-source AI brand icons**: integrates `@lobehub/icons-static-svg` for consistent provider and model brand icons across the model selector, provider settings, session cards, and share images.
- **Claude Code fast mode (`/fast`)** (#1970): supports `/fast [on|off]`, General Settings toggle, and composer Fast switch for eligible Claude models, with runtime status/cooldown sync and automatic degradation notices when switching to unsupported models.
- **Context-aware prompt optimization** (#1965): adds one-click prompt optimization in the composer, reusing active session context and prompt cache to refine drafts before sending.
- **Up/Down prompt history in composer** (#1957): press `ArrowUp` / `ArrowDown` at the top or bottom line of the composer to cycle through previous prompts from the current session and project history (`history.jsonl`).
- **Richer `AskUserQuestion` with images and notes** (#1961, #1972): supports pasting, picking, and dragging images with thumbnail previews, option notes, and smoother handoff back to chat.
- **Inline local audio playback** (#1969): renders local audio files (`.wav`, `.mp3`, `.m4a`, `.ogg`, `.flac`, `.aac`, `.opus`) and `data:audio/...` sources as inline audio players in chat messages and workspace Markdown previews.
- **Grok Official context windows & per-model overrides** (#1977): aligns Grok Official model context windows (500K for Grok 4.5–4.7, 256K for `grok-build-0.1`, 1M for Grok 4.20/4.3) and adds per-model context window overrides matching ChatGPT Official.
- **Opt-out for third-party cyber-risk prompts** (#1971): adds a setting to omit built-in Anthropic cyber-risk prompt instructions for third-party providers while keeping Claude Official OAuth accounts unchanged.
- **Mobile keep-awake & stabilized background reconnect** (#1974, #1980): adds a persisted "Keep screen awake" toggle under mobile Settings → Appearance (Android, iOS, and H5 Wake Lock), pauses heartbeat/reconnect loops while backgrounded, and resumes immediately with reset backoff on foreground return.

## Fixes

- **Local index sweep storms & subagent read starvation** (#1978, #1982): prevents prompt and subagent writes from triggering full local-index sweep storms, eliminating backend stalls when sending prompts or viewing subagents.
- **Preserve turn change cards through reconnect** (#1973): keeps expanded turn change cards, scroll position, and composer drafts intact across background tasks, history backfill, and idle reconnects, while guarding undo until checkpoints are ready.
- **Sidebar session context menu viewport clamping** (#1976, #1981): portals and clamps the sidebar session context menu to the viewport so bottom rows no longer clip actions off-screen.
- **iOS nested modal fixes** (#1939, #1966): replaces nested native Modals in mobile question and sheet flows with inline overlays to prevent UIKit / RN Fabric dismissal stalls on iOS.
- **Telegram residual stream state after errors** (#1944, #1962): clears accumulated text, placeholder state, and pending timers on mid-turn errors so subsequent turns do not merge stale output.
- **Prompt hook timeout double-stacking** (#1935, #1967): passes the parent abort signal directly into `execPromptHook` so explicit hook timeouts (such as `/goal`) are reported accurately instead of being silently cancelled.
- **Cross-session delivery state** (#1968): exposes session state and `targetState` in `ListSessions` and `SendSessionMessage` to distinguish queued, approved, and consumed messages.

- **Windows installers unsigned by default**: the SignPath signing application is still pending, so this release's Windows installers are unsigned and SmartScreen may warn; see the installation notes below.
- **Phone app 0.1.6**: includes the dual monochrome UI redesign, keep-awake setting, stabilized background reconnect, and iOS nested modal fixes; after the desktop v0.8.0 release is published, the new APK is built and attached automatically, and iOS ships through TestFlight.
