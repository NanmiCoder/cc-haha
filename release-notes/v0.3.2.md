# Claude Code Haha v0.3.2

This release focuses on **the desktop Workbench, built-in browser preview, web element selection editing, rich media context and long-session readability**.

Compared with `v0.3.1`, this release upgrades the right-hand area to a Workbench and connects preview/open flows for links, local files, changed files, images, videos and web element selection; it also keeps fixing desktop session permissions, send shortcuts, provider image compatibility, Mermaid, the message action bar and long-session performance.

## Highlights

- **Right Workbench + built-in browser**: the right panel switches between Files / Browser, with an address bar, loading state, child webview lifecycle and window bounds sync.
- **More complete preview and Open With**: assistant output, changed files, workspace files, localhost, local absolute paths and `/preview-fs` / `/local-file` all go through unified preview or Open With actions.
- **Web element selection editing**: Browser pages support element selection, screenshots, an edit bubble, annotated regions and clean composer backfill, making it easy to hand localized web page edits directly to the Agent.
- **More stable image, video and local file context**: image attachments are no longer treated as ordinary paths to Read; videos in assistant output play inline; OpenAI / DeepSeek image schema compatibility recovery is more complete.
- **Activity and per-session settings**: added an Activity profile and usage heatmap; reasoning effort, permission mode and scheduled task bypass permission all follow session or task semantics.
- **Continued long-session and Markdown readability polish**: targeted fixes for large Mermaid diagram readability, message hover areas, hiding task progress, session list memory pressure and WebKit offscreen painting.

## Fixes

- Fixed desktop provider streams possibly getting stuck in running forever, confirmation dialogs being blocked by permissions, Enter sending by mistake, and image attachments triggering Read failures.
- Fixed responsiveness issues in MCP settings and past-session navigation caused by spinners, stale requests overwriting newer ones, blank history, long session list scans and cache invalidation.
- Fixed Markdown / diff / Mermaid readability in dark theme, during streaming and with large diagrams.
- Fixed details such as an oversized message action bar hover hit area, the bar not collapsing after a click, and inline image gallery hovers interfering with each other.
- Fixed the Open With menu being too heavy in changed files, workspace files and completed messages, the menu not flipping, or not actually opening the editor.
- Fixed provider compatibility issues such as OpenAI text models rejecting images, DeepSeek not accepting `image_url`, and synthetic business errors not being localized.
- Fixed preview selection screenshot markers running out of the viewport, small targets being covered by badges, and the Activity profile edit button appearing in screenshots.
- Fixed stability issues such as desktop update checks blocking the UI, empty `agentTaskNotifications` causing scroll re-renders, and hidden task progress reappearing.

## Notes
