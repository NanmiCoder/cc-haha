# Claude Code Haha v0.4.0

This is a major release centered on **migrating the desktop framework from Tauri 2 to Electron**.

The migration was prompted by feedback from several users: the desktop app had noticeable performance problems on macOS, and on Windows a lot of behavior differed from macOS, where it was developed. The root cause is that Tauri uses each platform's system WebView (WebKit on macOS, WebView2 on Windows), so rendering and interaction naturally differ. This release switches to Electron's bundled Chromium as the rendering layer, adding that layer to remove cross-platform inconsistencies at the root. The trade-off is a larger installer than the Tauri version (it bundles the Chromium runtime), which is unavoidable with this choice.

Compared with `v0.3.2`, the built-in browser, Workbench, terminal, file picker, system notifications, tray, menus, window state and sidecar process management have all moved to the new Electron desktop runtime.

## Highlights

- **Desktop foundation switched to Electron**: the built-in browser, Workbench preview, terminal, notifications, tray, menus and window state on macOS / Windows / Linux all move to the new desktop runtime, making cross-platform behavior more consistent.
- **Built-in browser and Workbench adapted to the new shell**: preview, screenshots, web element selection and local file opening remain complete and more stable under the Electron shell.
- **Polished Agent command experience**: the `agent` slash command goes through the normal chat pipeline with streamed progress, the selection bubble is more stable, and session titles are generated in the user's language.
- **Better context and image input compatibility**: reading large images and common long screenshots is restored, and provider context window estimates are more accurate.
- **Provider update**: the MiniMax preset is upgraded to MiniMax-M3.

## Fixes

- Fixed Windows behavior that differed from macOS development, including custom window decorations, the taskbar identity (AppUserModelID), PowerShell terminal selection forwarding and window navigation (#665).
- Fixed sidecar child processes being left behind as orphans when quitting the app.
- Fixed menu bar ghosting on external displays on macOS.
- Fixed window drag regions not working in the sidebar, title bar and tab bar.
- Fixed the `agent` slash command: it now goes through the normal chat pipeline, streams execution progress, and the selection is editable before sending (#653).
- Fixed unstable quoting of chat content selections (#351), and the selection bubble not disappearing on scroll (#672).
- Fixed composer input state being lost after a browser screenshot (#678).
- Fixed session titles only being generated after the assistant turn, and keeping them in the same language as the user.
- Fixed duplicate messages in Feishu fallback replies (#671).
- Fixed idle tabs being shown as active during prewarm (#681).
- Fixed expired sign-in state and connections in desktop sessions not recovering automatically (#658, #651).
- Fixed test inconsistencies caused by provider model name normalization (#620).
- Fixed several details after the Electron migration: proxy and fullscreen handling, Activity summary layout, social icon loading, and thinking details collapsed by default.

## Notes

- This version is not yet code signed for Apple / Windows, so the first install needs to be allowed manually once (see the installation notes below); this is not a damaged file.
- Online auto-update is not available yet: until Apple signing is in place, please download each new version manually from [GitHub Releases](https://github.com/NanmiCoder/cc-haha/releases) and install over the old one. Installing over the old version does not delete local data (`~/.claude`, `~/.claude/cc-haha` and custom portable data directories).

## Installation

Download the file for your system and CPU architecture from the Assets at the bottom of this page:

| Platform | File |
|------|------|
| macOS Apple Silicon (M series) | `Claude-Code-Haha-0.4.0-mac-arm64.dmg` |
| macOS Intel | `Claude-Code-Haha-0.4.0-mac-x64.dmg` |
| Windows x64 | `Claude-Code-Haha-0.4.0-win-x64.exe` |
| Linux x64 | `Claude-Code-Haha-0.4.0-linux-x86_64.AppImage` or `Claude-Code-Haha-0.4.0-linux-amd64.deb` |
| Linux ARM64 | `Claude-Code-Haha-0.4.0-linux-arm64.AppImage` or `Claude-Code-Haha-0.4.0-linux-arm64.deb` |

### macOS

Double-click the DMG and drag the app into Applications. If it reports "is damaged" or "cannot verify the developer" on first launch, run in Terminal:

```bash
xattr -cr /Applications/Claude\ Code\ Haha.app
```

You can also click "Open Anyway" in System Settings → Privacy & Security.

### Windows

Double-click the `.exe` to install. If SmartScreen warns, click **More info** → **Run anyway**.

### Linux

AppImage:

```bash
chmod +x Claude-Code-Haha-0.4.0-linux-x86_64.AppImage
./Claude-Code-Haha-0.4.0-linux-x86_64.AppImage
```

deb:

```bash
sudo apt install ./Claude-Code-Haha-0.4.0-linux-amd64.deb
```

On ARM64 machines, replace the file name with `...-linux-arm64.AppImage` / `...-linux-arm64.deb`.
