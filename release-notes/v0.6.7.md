# Claude Code Haha v0.6.7

This release adds **contextual side chats in the workspace** and **human review before an Agent Teams run**, plus **auto-answer after a timeout** and **chat appearance settings**. It also fixes oversized conversations that would not open, configuration lost to concurrent writes, and IM reconnects that silently started a new session.

## Highlights

- **Side chats**: type `/btw question` in the composer (or select text and pick "Ask in a side chat") to open a temporary conversation on the right of the workspace. It inherits the parent session's context and model but runs independently, so follow-up questions never interrupt the main task. Closing the tab or quitting the app clears it.
- **Human review before an Agent Teams run**: once a team plan is ready, a "Confirm before the team runs" card lets you change each member's agent preset, provider, model, task ownership and dependencies, with batch assignment and "inherit from lead". Members only start after you confirm, so cost is under your control before launch.
- **Auto-answer after a timeout**: enable it under `Settings → General → Auto-answer questions` and a pending question that goes unanswered past your chosen delay (1/5/10/30 minutes, 5 by default) is answered by a small model on that session using the conversation context. If it cannot tell, it keeps waiting; any click or input from you cancels the timer.
- **Chat appearance**: `Settings → General → Chat appearance` controls chat font (system / sans-serif / serif / monospace), font size (12–24px) and conversation width (standard / wide / full), with a preview. It applies independently of the interface zoom scale and is saved per device.

## Models and providers

- **Claude Opus 5.5**: adds `claude-opus-5-5` (1M context, low through max reasoning effort) and makes it the default for official accounts; Claude OAuth compatibility is aligned with 2.1.281.
- **OpenAI official accounts**: adds GPT-6 Astra, GPT-6-Sol and GPT-6-Luna, with GPT-6-Sol as the new default.
- **OAuth model mapping**: every official account card in `Settings → Providers` gains an "OAuth model mapping" panel where the main / sonnet / haiku / opus / fable slots can be pointed at a model that account actually has, or given a hand-written alias.
- **Output budget for direct Anthropic providers**: your configured output ceiling is no longer overwritten with a fixed value **@omazili-guga** (#1392).
- **Grok Fable slot**: the Fable slot is wired into the model mapping system, including cc-switch import and the runtime environment **@MrWangBigData** (#1369).

## Fixes

- **#1373 Oversized conversations would not open**: conversations whose history exceeds 20MB no longer fail with "prompt too long". Compaction now computes the discard amount from the real token limit reported by the provider and reserves room for the reply; oversized messages no longer cause the whole metadata record to be skipped, so the title, working directory, model and permission mode stay intact.
- **A temporary IM disconnect started a new session**: a failed reconnect no longer silently swaps in a fresh session and loses context or resets the project directory; the original binding is kept and you are asked to retry **@yuehua-meng** (#1381).
- **Concurrent scheduled-task writes**: concurrent runs no longer overwrite each other's schedule, and deleted tasks no longer come back **@yuehua-meng** (#1371).
- **Memory edit save conflicts**: typing while a save is in flight no longer drops you out of edit mode, hides unsaved text, or gets blocked by your own previous revision **@yuehua-meng** (#1372).
- **Reading half-written team config made teams vanish from the UI**: every write path now takes the file lock and writes atomically **@yuehua-meng** (#1387).
- **Silent failure of auto-naming on thinking models**: the background title request no longer spends its whole token budget on thinking and leaves the title as the first message's placeholder **@realLoganLuo** (#1340 / #1382).
- **Vertical scrolling ran the wrong way on Windows** **@MikhailTail** (#1378).
- **CORS preflight caused `Failed to fetch`**: OPTIONS preflights from local origins are answered before the H5 gate, while remote origins are still rejected **@MrWangBigData** (#1369).
- **Malformed tool arguments could stall the run**: when a model emits invalid JSON for a tool call, the arguments are no longer silently degraded to `{}` and executed; the explicit error is fed back so the model can retry.
- **Lost session model selection**: reopening a session no longer resets the model to the default, and removing a provider no longer leaks its old model and effort onto a different provider.
- **Duplicate prompt**: appending a steering message mid-generation no longer makes it look like the same prompt was sent twice.
- **Chat content vanishing after a tab switch or a stop**: switching to the terminal or workbench and back keeps the chat view and scroll position; reloading history after stopping no longer deletes or duplicates messages that already arrived.
- **Side chats would not scroll**, workspace file tree actions and independent preview controls are restored, tab drag exclusions are confined to the viewport, and switching between tabs preserves the chat.
- **Image forwarding**: Space Bunny images and Kimi K3 images survive the OpenCode Go path.
- **Local Markdown links** keep their target, and **generated output files** resolve against the declared project roots.
- **Also**: long activity profile names wrap, `/clear` is searchable again, the checkpoint preview no longer shows the budget, auto-answering is now purely a model decision, review state after a rewind is cleared, and session discovery is bounded and reports history page limits.

## Other

- **Remotion skill pack**: the extensions page gains a Remotion skill pack (the official 12 skills, without the runtime or renderer) for building procedural video with React.
- **Site and documentation redesign**: the landing page is rebuilt with a four-step workflow and real usage cases; the docs site gains five new walkthroughs (reading an unfamiliar project, fixing a bug, shipping a feature, daily code review, handing off from a phone); first-time visitors get the site language matching their browser.
