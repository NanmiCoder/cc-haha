# Claude Code Haha v0.6.1

本次更新以 **Computer Use 的底层重构**为主：原生操作改由一个持久化的隔离工作进程执行，Agent 可以在后台连续点击、输入、滚动和拖拽，不必为每个动作等待一次模型往返，整体更接近 Codex 的后台操作体验。同时带来会话保留时长、桌面端历史浏览和一批修复。

## 新增与改进

### Computer Use 原生操作重构，对齐 Codex

- 新增持久化的隔离 JavaScript 工作进程执行原生应用操作，可批量完成已知动作，动作之间不再需要模型往返。
- 对齐 macOS 的手势、按键、应用清单、截图、滚动和剪贴板行为，并补齐已签名原生接收端的回归测试。
- 坐标点击改为走精确的辅助功能命中；渲染期属性可复用；键盘宏被限制在已验证的原生边界内。
- 截图附带像素尺寸，保留无损采集证据的同时只向模型返回受限尺寸的画面；窗口被遮挡层接管后仍保留窗口身份与快照。
- 取消操作可贯穿后台进程与锁获取，不再出现取消失效。
- 移除旧的逐应用限制，改为启用 Computer Use 时做一次全局授权，同时保留全局关闭与目标校验。
- 保留 Windows 的像素操作路径，修复取消操作时的清理问题。

### 会话与历史

- **会话记录默认保留 365 天**，可在「设置 → 通用」修改；修改时会预览将被清理的文件数量并要求确认。方案、文件历史、调试日志、粘贴内容和工作树仍保持 30 天。
- **桌面端完整历史浏览**：侧边栏近期列表之外的历史会话仍可访问，仅在打开时加载，并支持按项目滚动加载更早的会话（Refs #1287）。
- **IM 恢复项目会话历史**（#1286）：各 IM 适配器共享项目与会话选择，恢复失败时保留原有绑定，并与桌面端同步权限。
- 清理会话时一并清理对应的 subagent 记录；批量清理接口限制为桌面进程令牌，H5 令牌无法一次清空全部记录。
- 撤销「按会话 API 协议限制模型切换」的改动，已有会话可继续使用，模型可自由切换。

### 模型与 Provider

- **新增 Fable 5.1**（#1294）：加入官方模型目录与服务端兜底列表，支持推理强度档位（low / medium / high / xhigh / max，默认 high）。
- **新增 ApiSmart 赞助商与图片生成支持**：接入 ApiSmart 作为图片生成后端，并在 README 中展示赞助信息。
- **DeepSeek 视觉图片**（#1304）：修复 OpenAI Chat 转发中丢失 DeepSeek 图片输入的问题。
- **Anthropic 兼容端点重复 `/v1`**（#1279）：在 Anthropic 请求边界归一化 API 版本，保留网关前缀与已保存的 Provider 设置。
- 保留 Provider 的 1M 上下文标记与显式能力开关，跨上下文别名时能力识别不再丢失。

### Codex 请求路由与工具载荷

- 可选参数的工具改为显式非严格 schema，不再因为缺少可选字段而丢失参数。
- 发送稳定的会话与线程标识，路由状态在一个用户回合内保持、在完成或取消时释放。
- 支持时用 zstd 压缩 Codex OAuth 请求体，同时保留可读的请求审计数据，并提供本地兼容开关。

## 修复

- **MCP 连接竞态**（#1299）：关闭与重连不再互相覆盖，禁用状态在在途重连结果返回后仍然生效，连接清理逻辑统一。
- **工具结果中的媒体丢失**（#1301）：跨 Provider 与 MCP 路径保留工具结果里的图片等媒体内容。
- **运行中丢失聊天历史**（#1284）：实时更新时保留已持久化的历史，流式重试清理在历史恢复后重新对齐（#1296）。
- **运行时配置错误后历史丢失**（#1303）：将配置选择被拒绝视为非终止错误，仅存在配置错误时恢复完整记录。
- 桌面端：创建会话后保留所选项目目录；活动摘要按唯一文件统计修改数量；缓存 Token 说明更清晰。

# Claude Code Haha v0.6.1

This release is headlined by a **ground-up rebuild of Computer Use**: native actions now run inside a persistent, isolated worker process, so the agent can click, type, scroll and drag in the background without a model round trip between each input, moving closer to Codex's background-operation experience. It also brings session retention, desktop history browsing and a batch of fixes.

## New & Improved

### Computer Use native automation, rebuilt

- A persistent isolated JavaScript worker performs native app actions and batches known operations, removing the model round trip between actions.
- macOS gesture, key, app inventory, capture, scroll and clipboard behavior now align with Codex, backed by a signed native receiver fixture and regression tests.
- Coordinate clicks route through the exact accessibility hit, render-local attributes are reused, and keyboard macros stay within validated native boundaries.
- Screenshots carry pixel dimensions and keep lossless capture evidence while returning bounded images to the model; window identity and snapshots survive overlay takeover.
- Cancellation propagates through the daemon and lock acquisition instead of silently failing.
- Legacy per-app restrictions are replaced by a single feature-wide consent when Computer Use is enabled, keeping global disablement and target validation.
- The Windows pixel path is preserved, with cancellation cleanup fixed.

### Sessions & history

- **Transcripts are kept for 365 days by default**, configurable in Settings → General, where a change previews the files to be removed and asks for confirmation. Plans, file history, debug logs, pastes and worktrees keep the 30-day window.
- **Full desktop history browsing**: conversations beyond the recent sidebar list stay reachable, hydrate only when opened, and load older sessions while scrolling within projects (Refs #1287).
- **IM project session history** (#1286): adapters share project and session selection, keep bindings on failed restoration, and sync permissions with desktop clients.
- Subagent transcripts are cleaned together with their parent session; the bulk cleanup endpoint is restricted to the desktop process token so an H5 token cannot wipe every transcript at once.
- Reverted the protocol-based model-switching restriction so existing sessions stay usable and models can be switched freely.

### Models & providers

- **Fable 5.1** (#1294): added to the official catalog and server fallback list with reasoning effort (low / medium / high / xhigh / max, default high).
- **ApiSmart sponsorship and image generation**: ApiSmart is available as an image-generation backend, with sponsor information shown in the README.
- **DeepSeek vision images** (#1304): fixed image inputs being dropped in OpenAI Chat relays.
- **Duplicate `/v1` in compatible endpoints** (#1279): normalize the API version at Anthropic request boundaries while preserving gateway prefixes and saved provider settings.
- Provider 1M context markers and explicit capability opt-outs are preserved across context aliases.

### Codex request routing & tool payloads

- Tools with optional arguments now use explicit non-strict schemas, so optional fields are no longer dropped.
- Stable session and thread identities are sent, with routing state retained for one user turn and disposed on completion or cancellation.
- Codex OAuth request bodies are compressed with zstd when supported, while readable request audit data and a local compatibility opt-out are retained.

## Fixes

- **MCP connection races** (#1299): close and reconnect no longer overwrite each other, the disabled state survives in-flight reconnect results, and connection cleanup is unified.
- **Media in tool results** (#1301): images and other media in tool results are preserved across provider and MCP paths.
- **Chat history lost while tasks run** (#1284): durable history is preserved during live updates and stream retry cleanup is rebased after hydration (#1296).
- **History lost after runtime config errors** (#1303): rejected runtime selections are treated as non-terminal errors, restoring the full transcript.
- Desktop: keep the selected project directory after creating a session, count unique edited files in the activity summary, and clarify cached-token accounting.
