# Claude Code Haha v0.4.10

This is a stability and recovery release after `v0.4.9`. It fixes edge cases in session restarts, background Agents, permission denial, H5 disconnects, conversation search and Windows in-place upgrades, and completes startup diagnostics, recovery from proxy fluctuations, model role configuration and headless H5 deployment.

Compared with `v0.4.9`, this version preserves the real "completed, stopped, denied" states more reliably. After an app cold start, network fluctuation or leaving H5 on a phone, terminal states should no longer revert to running, and unexecuted writes should no longer show up as file changes. The Windows installer more accurately identifies processes that are actually holding the install directory, and protects user data from before the upgrade.

## Highlights

- **More trustworthy session recovery and undo**: undoing the current turn now uses a real checkpoint; context is flushed to disk before restart, restoring past sessions no longer triggers prewarm by mistake, and long conversations keep their reading position after remounting.
- **Persisted background task terminal states**: background Agent completed, failed and stopped states are written to session history; after fully quitting and restarting, completed cards no longer revert to "in progress", and the old notification format can still be read.
- **H5 disconnect cleanup covers the startup race**: when a phone leaves during CLI startup and a permission request appears afterwards, the server still sets up cleanup observation; unattended permission waits stop after a limit, while reconnects and normal long tasks are not killed by mistake.
- **Hardened Windows in-place upgrade**: the installer checks related processes more accurately and handles current-user installs and old data recovery, reducing CLR HRESULT errors, false "program still running" reports and forced uninstall-reinstall.
- **Stable conversation search and scrolling**: virtualized long conversations support reliable search, directional navigation and current-match positioning; fast typing, content refreshes and component remounts no longer let old results overwrite new ones or pull the scroll position back to the bottom.
- **More recoverable proxy, startup and diagnostics**: system proxy connection resets no longer trigger main-process JavaScript exceptions; a startup error is shown when the renderer entry fails; SDK diagnostic messages have a retention limit to avoid growing memory over long runs.

## Fixes

- Fixed turns that ended abnormally only being undoable after a restart, or being undone to the wrong file state; the server-side authoritative checkpoint is now used and only the target turn is rolled back (#1030).
- Fixed context not being fully flushed to disk before a runtime restart, and extra prewarm when restoring a session possibly polluting context (#1033, #1054).
- Fixed scroll position being lost after remounting long conversations, and arrow keys, the current match and highlights getting out of sync when search results update (#1045, #1057).
- Fixed background Agent completion notifications possibly affecting foreground output when running concurrently with a foreground Skill, and terminal states reverting to "in progress" after a cold start (#1047).
- Fixed interrupted past tasks staying in running for a long time; unfinished turns now settle to "stopped", while truly completed turns stay "completed" (#1034).
- Fixed the current turn continuing after an ordinary tool was denied, and denied Write/Edit operations appearing in the changed-files card and workspace changes even though nothing was written (#1051).
- Fixed cleanup observation not taking effect when H5 had already left but a permission request appeared later; reconnect-cancels-cleanup and normal background execution semantics are kept (#1019).
- Fixed main-process exceptions popping up when switching system proxy nodes, briefly losing network or on connection resets, and still needing a restart after the network recovered (#1050, #1056).
- Fixed Windows current-user in-place installs possibly hitting CLR HRESULT, misdetecting leftover processes, wrongly blocking installation or damaging old data recovery (#1028, #1029, #1036).
- Fixed the app being left with only background processes and no visible error window when the renderer entry failed to load (#1032).
- Fixed the sidecar keeping too many SDK diagnostic events for a long time and continuously growing memory, while keeping live replies and key error information (#1049).
- Fixed the native browser preview being misaligned with the React container bounds after app zoom and window changes (#1042).
- Fixed the tab lingering after closing the last preview tab, requiring an extra action to leave preview (#1038).
- Fixed different message shapes possibly causing inconsistent state calculation when attachments take part in context analysis (#1022).

## Features and Improvements

- The model selector merges the main model and role models such as Haiku, Sonnet and Opus from the runtime configuration, and keeps the current model after restart (#1024).
- In-conversation find adds a positioning bridge for virtualized message lists, so it can reliably find and jump within large message histories.
- The H5 docs add a headless server build and deployment path, and the release flow includes the Web UI artifacts in the sidecar build (#1027).
- Proxy Trace disk writes are decoupled from response completion, so slow disks or large traces no longer block users from seeing the final reply (#1014).
- WebSocket and the session service add ordered writes, deduplication and old format compatibility for background task terminal states, so multiple observers never persist the same notification twice.
- Windows release smoke adds install process checks, default-mode reinstall and old directory data recovery coverage.

### macOS

Double-click the DMG and drag the app into Applications. Officially signed and notarized builds should pass the normal Gatekeeper flow directly.

### Windows

Double-click the `.exe` to install. Run it as the current user; do not use **Run as administrator**. Fully quit the app before upgrading in place; if the installer reports related processes still running, close them as prompted and try again. If SmartScreen warns on an unsigned build, choose **More info** → **Run anyway**.

### Linux

AppImage:

```bash
chmod +x Claude-Code-Haha-0.4.10-linux-x86_64.AppImage
./Claude-Code-Haha-0.4.10-linux-x86_64.AppImage
```

deb:

```bash
sudo apt install ./Claude-Code-Haha-0.4.10-linux-amd64.deb
```

On ARM64 machines, use the matching `linux-arm64` files.
