# Claude Code Haha v0.1.0
The first official desktop release of Claude Code Haha: a cross-platform client built on Tauri 2 + React, with multiple sessions, desktop control, code preview, permission management and local service integration.

## What's included
- Cross-platform desktop app with multi-tab, multi-session management
- Improved rendering for Markdown, code blocks and code diffs
- Dedicated display panels for tool calls such as Bash, Read, Edit and Write
- Slash commands, `@` file search, attachment upload and image preview
- Permission request dialogs and AI follow-up question interaction
- Multi-provider model configuration and resource management
- Official Claude account sign-in, with the desktop OAuth callback fixed
- Scheduled task management panel
- IM platform adapters (Telegram / Feishu)
- Agent team status visualization
- Desktop control configuration and system permission integration
- End-to-end packaging and release pipeline for Windows / macOS / Linux

## Key improvements
- Fixed official Claude sign-in authorization and callback errors on desktop
- Fixed a rendering bug that incorrectly hid earlier replies
- Fixed Linux packaging build stability
- Improved the packaging strategy for environments without a developer certificate or update certificate
- Unified installer build and artifact output conventions across all three platforms

## Downloads
- macOS (Apple Silicon): `.dmg`
- macOS (Intel): `.dmg`
- Windows: `.exe` / `.msi`
- Linux: `.deb`

## First-time installation
**macOS**
The installer is not signed by a developer, so the system will block it.
If you see "is damaged" or "cannot verify the developer", run in Terminal:
```bash
xattr -cr /Applications/Claude\ Code\ Haha.app
```
