# Claude Code Haha v0.1.3
This release focuses on desktop experience fixes and capability improvements, addressing frequently reported issues: Skills discovery, session management, Computer Use authorization and overall desktop usability.

## Key updates
### 1. Fixed desktop not recognizing project-level custom Skills
Issue: [#82](https://github.com/NanmiCoder/cc-haha/issues/82)

Previously the desktop app only read user-level Skills and could not see `.claude/skills` inside the project directory, so project-level custom skills were invisible and unusable.
`v0.1.3` fixes project-level Skills scanning and loading, aligning desktop behavior with the CLI / WebUI.

### 2. Fixed tabs not closing after a session is deleted
Issue: [#80](https://github.com/NanmiCoder/cc-haha/issues/80)

Deleting a session from the left list left its tab open on the right, causing inconsistent UI state and accidental actions.
The new version links the two, so deleting a session also closes its tab and the UI stays consistent.

### 3. Added desktop theme switching and improved diff preview
Issue: [#73](https://github.com/NanmiCoder/cc-haha/issues/73)

The desktop app now supports switching between light and dark themes to reduce eye strain during long sessions.
Code comparison and file diff previews have an improved layout tuned for reading code.

### 4. Fixed the Computer Use `request_access` authorization dialog not appearing
Issue: [#70](https://github.com/NanmiCoder/cc-haha/issues/70)

In earlier versions, calling desktop control could not bring up the authorization dialog, leaving permissions empty and the feature unusable.
This release completes the permission request bridge, adds a visual authorization dialog and improves error messages, greatly improving Computer Use on desktop.

## Summary
`v0.1.3` is a small experience-fix release. Key changes:
- Fixed project-level Skills loading
- Fixed tabs not syncing when a session is deleted
- Added system light / dark theme switching
- Improved code diff preview
- Fixed desktop control authorization failures

Thanks to everyone who reported feedback and filed issues. If problems persist after upgrading, please keep the feedback coming.

## Installation
**macOS**
If the app reports "is damaged" on first launch, run:
```bash
xattr -cr /Applications/Claude\ Code\ Haha.app
```
