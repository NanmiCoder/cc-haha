# Claude Code Haha v0.6.8

This release adds **local voice dictation**, **document preview in the workspace** and a **curated skills catalog**, plus **highlights for sessions waiting on you** and **per-format file icons**. It also fixes "Stop & Close" leaving background tasks alive, every later message failing after a request-too-large rejection, replies to background task notifications being swallowed, and Grok rejecting the CLI with HTTP 426.

## Highlights

- **Local voice dictation**: a microphone button sits beside the composer — click to record, click again to stop. The audio is resampled to 16 kHz mono PCM16 WAV and transcribed by a local worker; the text lands in the draft and is not sent. If the draft changed or an IME is composing, the result waits behind an insert button. `Settings → Voice input` controls the switch, language and microphone, and includes a test transcription with a live waveform. The engine and model are downloaded at runtime with pinned sha256/sha512 checks, resumable transfers and retry after an interruption; you can pin the download source to the official host or a domestic mirror, and a cancelled download keeps what was already fetched. Electron desktop only; not yet verified on Windows or Linux, with a real microphone, or in a signed and notarized build.
- **Document preview in the workspace**: PDF, Word and Excel files the agent writes open in the workspace panel instead of another application, with zoom and fit, per-file memory of scroll position, zoom and sheet, and a refresh when the file is rewritten. Local images the agent mentions (outside the working directory, `~`, `C:\`, `file://` paths) render in the conversation, and images returned by tools such as Read appear as thumbnails under the call. Documents outside the workspace still open in the system application. **@olo12119** (#1397)
- **Curated skills catalog**: the skills market opens on a bundled catalog of 398 curated ClawHub and SkillHub skills in 13 categories instead of querying both registries live. "Search all markets" stays available as an explicit scope and its results are marked as not curated. The detail page gains stats, a security report, a changelog, a capability panel and triggers, and installing an unaudited or flagged skill requires an acknowledgement. ClawHub skills are pinned to the card's owner so a same-slug copy by another author is never shown or installed in its place.
- **Highlighting sessions waiting on you**: when a session produces a card that needs your decision (AskUserQuestion, a permission request), its tab and sidebar row are marked so you do not have to open each one to find it. **@kizemo** (#1391)
- **Per-format file icons**: generated-file cards, the turn change card and message attachments render a colored, labelled file icon by extension (PDF red, Word and Markdown blue, Excel green, PowerPoint orange, archives amber, code purple) instead of one grey glyph.

## Models and providers

- **Claude Sonnet 5.5**: adds `claude-sonnet-5-5` (1M context, low through max reasoning effort) and refreshes the model catalog and the "latest models" line of the environment prompt (knowledge cutoff aligned to June 2026).
- **GPT-6.1-Sol**: `gpt-6.1-sol` is supported in the desktop app and through Codex OAuth (258,400 context, low through max, low by default).
- **Fable models**: configured Fable models now appear in the model selector.
- **Grok HTTP 426**: aligning the CLI proxy identity with 1.0.46 clears the upgrade demand.

## Fixes

- **"Stop & Close" left tasks running**: a background shell command and its CLI session kept running, so the reopened session spun again and closing asked the same question once more. Stop & Close now stops every running background task before the socket closes, and "is the session running" and "which tasks to stop" share one predicate. **@zyr017** (#1398)
- **Every later message failed after a request-too-large rejection**: the error now reports the size actually sent, how much of it is images or documents, and whether the provider or the relay rejected it; afterwards the images and documents that request carried (including media nested in tool results and `@`-mentioned attachments) are replaced with placeholders so the next message goes through. Compaction shares the same placeholder logic. **@hemppp** (#1399)
- **Misleading copy for oversized requests**: the message no longer blames the selected model or tells you to delete large files by hand.
- **Replies to background task notifications were hidden**: what the model said once a background command finished, and any tool work after it, now reaches the chat both live and on reload. **@CyL-Cly** (#1389)
- **The whole window became the error page on session reload**: an AskUserQuestion option description the server rejected as invalid reproduced on every launch; the card now renders only the fields it can show, and each transcript row has its own error boundary. **@kizemo** (#1400)
- **Slower cold start and session lists falling back to full scans**: one oversized transcript (over 8 MiB) no longer degrades the whole index, so session lists keep being served from the local index instead of scanning history files on every cold start.
- **Opening workspace files and loading images**: a file written through a symlinked path is now recognized as a workspace file and opens in the workspace; when a local image fails to load in the web UI or H5, it is retried once through the credentialed channel (the browser used to block it and the chat showed "unable to load image"); numbers in spreadsheet previews are no longer clipped to `12,000...`.
- **Scheduled tasks returning 500**: a `scheduled_tasks.json` written with a UTF-8 BOM (PowerShell 5.x) or left blank by an interrupted write no longer breaks listing and creation; content that has data but does not parse still throws and is never overwritten.
- **PDF read state**: the read-before-write state of a PDF is no longer lost.
- **Permission modes**: switching a permission mode now uses the live module binding instead of a stale value.
- **`@` mentions**: bundled skills such as imagegen now show up in the `@` list, evaluated against the current session's provider runtime environment. **@NanmiCoder** (#1420)
- **Also**: Markdown image paths resolve `~/`-relative parents, oversized conversations keep their workspace change record, a failed Markdown image shows a retryable error, and the preview's fit control gets its own icon and is disabled while already fitted instead of staying lit and doing nothing.
