# Claude Code Haha v0.1.7

This patch release focuses on Windows desktop auto-update reliability and chat display fixes.

Compared with `v0.1.6`, it fixes the local service failing to start after a Windows desktop auto-update, and completes macro preloading when the WebUI launches the CLI in a Windows development environment. It also fixes Mermaid rendering error display and manual chat scrolling being interrupted.

## Main updates

- Fixed the Windows desktop auto-update flow: the local server sidecar and adapter sidecar are now stopped before installing a new version, avoiding `os error 32`, "The process cannot access the file because it is being used by another process" or "Local service failed to start" on restart after upgrading.
- Windows release artifacts now prefer the NSIS installer, and an installer hook cleans up sidecar processes, reducing the chance of upgrades from older versions getting stuck on file locks.
- Fixed the WebUI failing to start the CLI in a Windows development environment: the source fallback now correctly loads `preload.ts`, avoiding startup failures caused by `MACRO is not defined`.
- Improved manual scrolling in the chat list: when you scroll up to read history, streaming output no longer forces the view back to the bottom; when you stay near the bottom, it keeps following the latest reply.

## Fixes

- Fixed Mermaid chart rendering failures sometimes showing a development error overlay; the error state now stays inside the chat message.
- Fixed the manual scroll position being overwritten during streaming, with added regression tests.
- Fixed the Windows updater not releasing sidecar file handles before installation.
- Fixed the CLI process exiting immediately with code 1 when starting a session in the Windows dev WebUI.

## Other notes

- Windows users on `v0.1.5` or `v0.1.6` can normally upgrade directly to `v0.1.7` without uninstalling the old version first.
- If a machine is already stuck on the "Local service failed to start" page after upgrading from an older version, fully quit the desktop app and any leftover `claude-sidecar.exe` processes, then install `v0.1.7`.
- The GitHub Release body still comes from `release-notes/v0.1.7.md`, so the Markdown no longer has to be copied by hand.

## Installation

### macOS

If the app reports "is damaged" or "cannot verify the developer" on first launch, run:

```bash
xattr -cr /Applications/Claude\ Code\ Haha.app
```
