# Claude Code Haha v0.4.1

This is the first patch release after the `v0.4.0` Electron migration. It focuses on desktop observability, IM adapter capabilities and a multilingual interface, and fixes session stability and release packaging details exposed by the migration.

Compared with `v0.4.0`, this version adds session trace monitoring, letting you inspect model requests, tool calls, message flow and key events on desktop; it also strengthens the WhatsApp / Telegram adapters, the settings experience, the image/screenshot pipeline and provider/runtime edge cases.

## Highlights

- **Session Trace Monitoring**: added session Trace recording and viewing, showing LLM requests, tool calls, message details, timings and errors per session; the Trace UI is upgraded to a two-pane tree layout closer to LangSmith, and its entry point is consolidated into Settings.
- **Stronger IM adapters**: added WhatsApp linked-device support with improved pairing, media handling and a desktop settings entry; Telegram gains a command menu, so common actions no longer require typing commands by hand.
- **Desktop localization completed**: added Japanese, Korean and Traditional Chinese interfaces, and filled in text for newly added settings, Trace, Adapter and other pages.
- **Smoother desktop settings and workflows**: added desktop Output Style configuration, the plugin list supports bulk enable/disable, and the Memory page is now preview-first with the Markdown editor filling the panel.
- **More reliable screenshots and preview**: preview screenshots now use native Electron capture, and the preview window closes on renderer reload, reducing leftover windows and screenshot state.

## Fixes

- Fixed the server possibly restarting a session too early when permissions or runtime configuration were changed during an active turn; this is now deferred until the current turn completes (#626).
- Fixed abnormal states or incomplete exit paths when prewarm / resume / shutdown interleaved (#611).
- Fixed concurrent worktree configuration writes possibly overwriting each other (#572).
- Fixed the missing stall timeout when OpenAI-compatible provider streams produce no output for a long time (#548).
- Fixed OpenAI chat completion test requests wrongly using the stream form (#638).
- Fixed the desktop output style setting not being written correctly or used for session startup (#652).
- Fixed persisted chat images being lost after restoring a past session (#721).
- Fixed lost styling of history quote cards created from selected chat text, and permission mode not restoring correctly after leaving plan mode (#623).
- Fixed incomplete error details when a tool call fails (#625).
- Fixed Memory files opening in edit mode by default and the Markdown editor being too short (#533).
- Fixed scheduled task notification polling starting before the server was ready.
- Fixed diagnostics noise from recording expected states as errors, and isolated related test state.
- Fixed the connection being lost because the login socket restarted after WhatsApp pairing completed.
- Fixed outdated install and setup guidance in the IM adapter settings page.
- Fixed the release workflow passing empty signing environment variables to electron-builder when signing secrets are not configured.

## Notes

- The GitHub Release body still comes from `release-notes/v0.4.1.md`.
- This version changes Trace capture, the provider proxy, WebSocket session lifecycle, IM adapter sidecars and the Electron preview screenshot pipeline; before release, run at least `bun run verify` and do a real smoke test of desktop Trace, WhatsApp/Telegram, preview screenshots and provider requests.
- The desktop release version comes from `desktop/package.json`; the root `package.json` still keeps `999.0.0-local` for local development.
- If this version is still not code signed for Apple / Windows, the system may require you to allow the first install manually once (see the installation notes below). Installing over the old version does not delete local data (`~/.claude`, `~/.claude/cc-haha` and custom portable data directories).

## Installation

Download the file for your system and CPU architecture from the Assets at the bottom of this page:

| Platform | File |
|------|------|
| macOS Apple Silicon(M series) | `Claude-Code-Haha-0.4.1-mac-arm64.dmg` |
| macOS Intel | `Claude-Code-Haha-0.4.1-mac-x64.dmg` |
| Windows x64 | `Claude-Code-Haha-0.4.1-win-x64.exe` |
| Linux x64 | `Claude-Code-Haha-0.4.1-linux-x86_64.AppImage` or `Claude-Code-Haha-0.4.1-linux-amd64.deb` |
| Linux ARM64 | `Claude-Code-Haha-0.4.1-linux-arm64.AppImage` or `Claude-Code-Haha-0.4.1-linux-arm64.deb` |

### macOS

Double-click the DMG and drag the app into Applications. If it reports "is damaged" or "cannot verify the developer" on first launch, run in Terminal:

```bash
xattr -cr /Applications/Claude\ Code\ Haha.app
```

You can also click "Open Anyway" in System Settings → Privacy & Security.

### Windows

Double-click the `.exe` to install. If SmartScreen warns, click **More info** → **Run anyway**.

### Linux

AppImage:

```bash
chmod +x Claude-Code-Haha-0.4.1-linux-x86_64.AppImage
./Claude-Code-Haha-0.4.1-linux-x86_64.AppImage
```

deb:

```bash
sudo apt install ./Claude-Code-Haha-0.4.1-linux-amd64.deb
```

On ARM64 machines, replace the file name with `...-linux-arm64.AppImage` / `...-linux-arm64.deb`.
