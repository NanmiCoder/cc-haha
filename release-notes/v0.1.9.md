# Claude Code Haha v0.1.9

This release focuses on workspace file management in the desktop right panel, reviewing and reverting file changes, and third-party Provider compatibility.

Compared with `v0.1.8`, the biggest change is a new workspace file panel on the right side of desktop sessions. You can browse project files, preview content, review file changes from the current turn and the whole session, and add files to the chat as context. This version also improves project selection on the start page, checkpoint rewind, diffs in non-Git directories, third-party model thinking / WebSearch compatibility, closing the desktop window to the background and restoring window position.

## Main updates

- Added a workspace file panel on the right side of desktop sessions: browse the current project directory, view the file tree, and preview text files and local images while in a session.
- View file changes made in a session: see added, modified and deleted files with their diffs in the right panel; changes are shown from the session record even when the working directory is not a Git repository.
- Choosing a project directory on the start page immediately creates a draft session, so file management, the changes view, runtime selection and the terminal toolbar are available before the first prompt.
- Added a current-turn changes card: after each reply completes, the chat shows that turn's changes so you can review them before deciding whether to revert.
- File revert is consolidated into checkpoint rewind: the current-turn changes card can trigger file restore, and the revert target is located by the corresponding user message, reducing the risk of reverting to the wrong point in multi-turn sessions.
- Add files or partial content to the chat from the workspace file panel: the UI shows a readable file chip, while the content actually sent to the CLI keeps the native `@file-path` reference.
- When reloading a past session, `@file-path` references in the transcript are restored as attachment chips, so long absolute paths no longer appear in the user message body.
- Added desktop WebSearch configuration: choose Auto, Tavily, Brave, Claude native or Off in settings, and configure Tavily / Brave Search API keys.
- WebSearch gains unified capability resolution and fallback backends: Claude model names use Anthropic native WebSearch first, while third-party models or proxies that do not support the native server tool can fall back to Tavily / Brave.
- Added a desktop thinking mode toggle: new sessions can explicitly turn off thinking, supporting non-thinking requests to Anthropic-compatible endpoints such as DeepSeek, Kimi and GLM.
- Closing the main desktop window now keeps the app running in the tray; the local server and adapter sidecars are no longer stopped by an ordinary window close. The tray menu can show the window again or truly quit the app.
- The desktop app remembers the main window size, position and maximized state and restores them on restart, avoiding off-screen placement when external displays change.

## Fixes

- Fixed the right workspace panel showing an empty state by default when there are no changed files; it now shows the file tree first so you can still browse the project.
- Fixed workspace file preview edge cases: images are no longer caught by the text size limit, large text returns a capped preview, and binary files stay clearly non-previewable.
- Fixed inconsistent diff rendering between the chat changes card and the right panel by unifying the code preview surface, and improved readability in dark theme.
- Fixed fragile state caused by mixing workspace changes with session checkpoints: the right panel represents the project workspace state, while turn cards in the chat represent session checkpoint state.
- Fixed the current-turn changes card going missing in some sessions: when the visible user message ID does not match the persisted transcript ID, or the SDK file-history snapshot is missing, changes are extracted from the stable user message sequence and transcript tool calls instead.
- Fixed unstable revert semantics in multi-turn sessions, with added regression coverage for stale current-turn cards, target message location and dark-theme workspace tokens.
- Removed the old message hover rewind entry; file revert is consolidated into the current-turn changes card so two similar undo entries no longer coexist.
- Fixed WebSearch sometimes being unavailable with third-party Providers due to the `web_search_20250305` schema, proxy-layer capabilities or non-Claude model names.
- Fixed the WebSearch settings save button being squeezed onto a new line by description text on narrow Chinese layouts or in dark mode.
- Fixed inconsistent thinking parameters for third-party Anthropic-compatible Providers across the main session, side queries and AI title generation, reducing request failures from mismatched model capabilities.
- Fixed old desktop sessions still carrying an expired provider id after provider configuration changes, causing CLI startup failures or unusable sessions; the id is now validated before startup and falls back to a valid configuration.
- Fixed assistant messages containing only whitespace still rendering as empty bubbles in chat history or streaming output.
- Fixed missing visible diagnostics when the desktop app fails to start; the error now includes non-sensitive provider, model and startup context to help locate user-side problems.
- Fixed closing the window quitting the app on Windows / macOS desktop; background tasks and the local service lifecycle are now managed by the native Tauri layer.
- Fixed the desktop window losing its size and position after restart, while skipping old window states that are too small or invisible.
- Fixed the macOS Dock icon looking too small, and regenerated Tauri icon assets so the packaged icon matches the source files.

## Other notes

- GitHub Issue templates now collect desktop-oriented information first: operating system, desktop version, install source, provider/model/base URL, reproduction steps, configuration screenshots and full logs.
- A GitHub Star History section was added to the bottom of the README and English README, so users can see project growth and support the project.
- `.gitignore` now includes `.codex-logs/`, keeping local Codex run logs out of commits.
- WebSearch fallback currently requires you to configure a Tavily or Brave Search API key yourself; without a fallback key, non-Claude models will not be forced to expose an unusable native WebSearch.
- The GitHub Release body still comes from `release-notes/v0.1.9.md`, so the Markdown no longer has to be copied by hand.

## Installation

### macOS

If the app reports "is damaged" or "cannot verify the developer" on first launch, run:

```bash
xattr -cr /Applications/Claude\ Code\ Haha.app
```
