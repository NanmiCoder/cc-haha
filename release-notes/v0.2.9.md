# Claude Code Haha v0.2.9

This release focuses on **ChatGPT Official, unified AI network settings, session branching, Context Compact visualization, Provider compatibility and desktop stability**.

Compared with `v0.2.8`, the most important change is adding ChatGPT Official as a first-class desktop provider: you can choose ChatGPT Official in Settings, sign in with OpenAI OAuth, use the built-in model catalog, and have the session runtime automatically use the OAuth token and the matching Codex runtime environment. This release also unifies AI request proxy and timeout settings under General Settings, fixes a batch of compatibility issues with OpenAI / DeepSeek / Claude-compatible providers, and continues polishing desktop sessions: you can branch directly from a past message, context compact is shown as a timeline state, and background tasks, running sessions, retry waits and input layout are all clearer.

## Highlight

- **ChatGPT Official arrives on desktop**: Providers adds a built-in ChatGPT Official provider with OpenAI OAuth sign-in, sign-out, status display, an authorization link fallback, the official model catalog and OAuth runtime env injection.
- **More reliable OpenAI OAuth storage**: OAuth tokens move to unified file storage, with protection against old tokens, secure-storage cache, env-pinned OAuth files and half-written files, so old credentials are not wrongly revived after restart.
- **Unified AI network settings**: General Settings adds AI request proxy and timeout settings with system / manual proxy support, and the provider runtime, OpenAI-compatible proxy and session requests all use the same network configuration.
- **Branch directly from past messages**: user and assistant messages in a complete turn can now create a branch session; the branch keeps the correct history chain, workdir, worktree and related transcript metadata.
- **Context Compact becomes a readable state**: manual or automatic compact shows an in-progress state and a completion summary in the chat timeline, with an expandable view of the summary, trigger, tokens and message count.
- **Stronger Provider compatibility**: DeepSeek reasoning history, Claude attribution, Claude Code billing CCH, Codex OAuth token exchange, the OpenAI Codex context window and direct TUI provider env all have more robust compatibility paths.
- **More transparent desktop chat state**: session running state syncs to the TabBar and Sidebar; stopped background tasks no longer show as alive; API retries show the attempt count, wait time and error summary in the chat area.

## Main updates

- The Providers settings page adds a built-in ChatGPT Official card, pinned at the top of the provider list together with Claude Official.
- Added a desktop ChatGPT Official sign-in component that starts OAuth, polls status, shows the account, signs out, and lets you copy the authorization link to finish sign-in when the browser cannot be opened.
- Added the Haha OpenAI OAuth API and desktop store; login status never returns the token itself, the callback path goes through the desktop server, and the old `/callback/openai` path remains compatible.
- The ChatGPT Official provider uses the `openai_oauth` runtime kind and automatically injects `OPENAI_CODEX_OAUTH_FILE`, the OpenAI Codex endpoint, model mapping and context window information.
- The Model Selector adds a ChatGPT Official group and model catalog, and syncs the default model when switching providers, avoiding wrong leftover models between ChatGPT / Claude / custom providers.
- OpenAI OAuth token storage is unified at `~/.claude/cc-haha/openai-oauth.json`, with more complete handling of refresh tokens, id tokens, client ids, expiry refresh and atomic writes.
- General Settings adds an AI network section for the AI request timeout, system proxy or manual HTTP(S) proxy, with input validation and save feedback.
- The provider runtime env is split into its own service, reducing stale proxy / stale provider env leaking into the direct TUI, the conversation service or provider requests.
- The OpenAI-compatible proxy uses the unified AI network settings, and DeepSeek / opencode.ai scenarios keep reasoning content and the thinking toggle.
- Past session messages gain a "Branch from here" entry; the new branch session is truncated at the target message and keeps the necessary session metadata, worktree state, PR link, file snapshot and content replacement.
- The message action bar merges copy and branch into inline controls, reducing floating buttons covering message bubbles or jumping around in long text.
- During context compact the chat area shows a compacting state; after compact completes, an expandable summary divider is shown and restored from the transcript as structured state.
- During API retries the desktop chat area shows the retry state, attempt, HTTP status / network error, a wait countdown and an error summary, making long waits less opaque.
- The Sidebar and TabBar show running sessions based on both tab state and chat store state; background tasks stopped by TaskStop / KillShell update to stopped.
- Plugins / Skills browsing in Settings is further polished: Skills supports search, and the Plugins stats area and button layout fit both narrow and wide screens better.
- With multi-line input, the desktop composer toolbar now takes up natural space instead of covering the last lines of the textarea.
- The macOS desktop CLI launcher uses a more stable wrapper under an interactive TTY; launching the TUI directly from the native Terminal keeps direct input and is no longer disturbed by shell env capture.
- AGENTS.md was updated with a more compact agent operating contract, continuing to emphasize release notes, quality gates and this repository's automated release constraints.

## Fixes

- Fixed choosing ChatGPT Official saving only metadata and being lost or falling back to another provider after restart.
- Fixed ChatGPT OAuth authorization failing before the callback, the Codex OAuth URL being rejected, and mismatched token exchange request shapes.
- Fixed old OpenAI OAuth tokens, secure-storage cache or legacy token files being wrongly revived in a new login state.
- Fixed provider settings JSON writing the ChatGPT OAuth runtime env, which mixed runtime-only variables into the user's config file.
- Fixed the direct TUI launch reusing a stale provider proxy env, sending provider requests through the wrong proxy or provider environment.
- Fixed the AI proxy timeout in General not actually overriding the proxy request timeout.
- Fixed the OpenAI Codex context window being inconsistent with the auto-compact decision.
- Fixed DeepSeek reasoning history being lost in OpenAI Chat proxy conversion, preventing multi-turn reasoning context from round-tripping.
- Fixed Claude attribution being decided only by provider and not by model name, making the attribution policy for OpenAI-compatible providers inaccurate.
- Fixed the Claude Code billing header / CCH signature being incompatible with some upstream validation after proxy conversion.
- Fixed the sidecar being suspended by job control under an interactive TTY when launched from the macOS GUI or the launcher.
- Fixed the desktop UI still showing a task or session as running after its background task was stopped.
- Fixed inconsistent Sidebar / TabBar status indicators after switching tabs or navigating to Settings from a running session.
- Fixed the composer toolbar covering input content with multi-line input.
- Fixed stats cards, buttons and descriptions getting squeezed on narrow screens in the Settings extension browsing pages.
- Fixed unstable timing in workspace preview tests, reducing intermittent failures in coverage verification.

## Other notes

- The GitHub Release body still comes from `release-notes/v0.2.9.md`, so the Markdown does not have to be copied by hand.
- ChatGPT Official depends on a real OpenAI / ChatGPT OAuth sign-in; without an account or network, you can skip real requests and verify only the UI, model catalog and state recovery.
- This version includes changes to network proxy, OAuth tokens, provider runtime env and local config persistence; if provider requests fail after upgrading, first check the AI network settings in Settings -> General and the current provider in Providers.
- The Context Compact display and API retry state are chat timeline experience changes; before release, manually review them with a long session and a provider request that fails in a controlled way.
