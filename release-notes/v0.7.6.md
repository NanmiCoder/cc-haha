# Claude Code Haha v0.7.6

本次带来 **cc-haha 手机 App（Android / iPhone）**，手机连接也改用 **Cloudflare**：离开电脑也能在手机上看进度、审批、派任务。桌面端新增运行任务时防止系统休眠、在对话里管理定时任务、编辑并重发被停止的提示，供应商方面加入 OpenRouter 预设、按供应商设置代理和官方账号刷新模型列表；同时修复 Agent Teams 卡在收尾、长会话滚动位置、大图请求等一批问题。

## 核心功能

- **cc-haha 手机 App**（#1688，#1698，#1710，#1715，#1724，#1725，#1727，#1729，#1738，#1741，#1743）：在桌面「手机连接」里扫码配对自己的电脑后，可以在手机上看流式回复、审批工具权限和回答提问、发新任务、创建定时任务、浏览文件和改动。语音输入由电脑上已配置的语音服务转写。Agent 团队的方案可以在手机上审阅，逐个成员调整模型后启动；启动后按成员查看进度和消息，也能从手机停止团队。经 Cloudflare 连接时，工具截图按引用传输，弱网下重连更快。任务始终在电脑上执行，手机只和你的电脑通信。App 界面目前只有中文。
- **手机连接改用 Cloudflare**（#1735，#1740，#1742，#1728）：默认的「快速连接」不需要 Cloudflare 账号，自动生成二维码，手机扫码后在桌面上批准。也可以用自己的固定域名：直接粘贴 Cloudflare 给出的安装命令，只提取其中的 Token，不执行命令；Token 被拒或路由配错时直接给出原因。同一 Wi-Fi 下仍可直连。侧栏新增「手机连接」入口，「复制配对链接」复制的是带一次性配对码的完整链接。从旧版远程访问升级后，连接不会自动开启，需要重新开启并扫码。
- **运行任务时防止系统休眠**（#1730）：在 设置 → 通用 中开启后，有任务在跑时电脑不会休眠，屏幕仍可以关闭。默认关闭。
- **在对话里管理定时任务**（#1690）：可以用 `/schedule` 或直接让模型创建、修改、暂停、删除定时任务并查看执行记录。对话里会显示任务卡片，侧栏的定时会话带时钟标记。
- **编辑并重发被停止的提示**（#1700，#1733）：停止后还没收到回复的那条消息可以编辑后重发，编辑框支持 `/` 和 `@` 菜单。
- **供应商与模型**：新增 OpenRouter 预设（#1682）；自定义供应商可以单独设置网络代理，可选跟随全局、直连或手动（#1683）；Claude、ChatGPT、Grok 官方账号可以「更新模型列表」（#1717）；DeepSeek 默认使用 Flash 并开启 1M 上下文，已保存的映射不变（#1695）；WebSearch 新增独立的 DeepSeek 搜索后端，任何模型都能用（#1657）；精简模式可以使用 general-purpose 和 Explore 子 Agent、WebSearch / WebFetch 和任务清单（#1716）。

## 修复

- **Agent Teams**（#1694，#1701，#1666，#1723，#1659）：团队不再卡在「收尾中」；启动失败的团队可以取消，已中断的团队可以结束，没做完就结束的显示「已结束」；发给成员的追加消息不再让成员一直等待；任务负责人在各处显示一致；DeepSeek 等非 Claude 会话生成的子 Agent 和成员沿用当前模型；普通会话不再反复请求不存在的团队工作台。
- **长会话滚动**（#1670，#1711）：历史同步后保持滚动位置，切换标签后回到原来的阅读位置。
- **图片**（#1661，#1664，#1714，#1705）：图片预览可以在整个会话的图片之间切换，并支持下载和缩放；官方 DeepSeek 请求超过 40 MiB 时图片改走 Files API，避免 413；超过 20 张图的请求，每张图都缩到 2000px 以内；大图回合结束后会话不再一直显示忙碌。
- **定时任务与用量统计**（#1697）：启用定时任务后第一句话报 400 的问题已修复；Token 用量页少算输出 token 的问题已修复，升级后历史累计数会变大，这是更正后的数字。
- **上下文**（#1687，#1734）：上下文圆环和 `/context` 按供应商设置的回退窗口显示大小；切回会话标签时直接复用已算好的上下文用量。
- **其他桌面问题**：新会话草稿在发第一条消息前就能进入工作区（#1672）；晚启动的 MCP 会在已运行的会话里自动重连，供应商更新凭据后下一轮生效（#1641）；重试横幅可以展开并复制脱敏后的诊断信息（#1667）；渲染进程崩溃提示带退出码和重启入口，稳定运行后会恢复自动重载（#1721）；第三方模型拒答时提示写的是当前所选模型（#1658）；冷会话切换权限不再被并发启动覆盖（#1713）；修复供应商排序、update-config 技能和 Responses 空心跳导致的压缩问题（#1643）。
- **飞书**（#1655，#1722）：在桌面代理下可以正常连接；日志和诊断导出不再包含 app_secret。

## 其他

- **输入框工具栏**（#1654）：工具栏固定为一行，Agent 模式（标准 / 精简）移到「+」菜单。
- **Trace 目录**（#1691）：可以用 `CC_HAHA_TRACE_DIR` 把 Trace 放到单独目录，感谢 @gansuddd。

- Linux ARM64：`Claude-Code-Haha-0.7.6-linux-arm64.AppImage`、`Claude-Code-Haha-0.7.6-linux-arm64.deb` 或 `Claude-Code-Haha-0.7.6-linux-aarch64.rpm`

# Claude Code Haha v0.7.6

This release introduces the **cc-haha mobile app for Android and iPhone**, and phone connections now run over **Cloudflare**, so you can follow progress, approve requests and start tasks from your phone while away from the computer. The desktop can keep the computer awake while tasks run, manage scheduled tasks from a conversation, and edit and resend a stopped prompt. Providers gain an OpenRouter preset, per-provider proxies and model-list refresh for official accounts. It also fixes Agent Teams stuck while finishing, lost scroll positions in long sessions, large image requests and more.

## Highlights

- **cc-haha mobile app** (#1688, #1698, #1710, #1715, #1724, #1725, #1727, #1729, #1738, #1741, #1743): after scanning the QR code under **Phone connection** on the desktop to pair your own computer, you can follow streamed replies, approve tool permissions and answer questions, start tasks, create scheduled tasks, and browse files and changes from your phone. Voice input is transcribed by the speech service configured on your computer. Agent team plans can be reviewed on the phone and launched after adjusting each member's model; once running, progress and messages are grouped by member, and the team can be stopped from the phone. Over Cloudflare, tool screenshots are sent by reference, so reconnecting on a slow network is much faster. Work always runs on the computer, and the phone talks only to your computer. The app interface is currently Chinese only.
- **Phone connection over Cloudflare** (#1735, #1740, #1742, #1728): the default Quick connection needs no Cloudflare account, shows a QR code automatically, and asks you to approve the phone on the desktop. You can also use your own fixed domain by pasting the install command Cloudflare gives you; only its token is extracted and the command is never run, and a rejected token or misrouted hostname is reported directly. Same-Wi-Fi direct connections still work. The sidebar gains a **Phone connection** entry, and **Copy pairing link** copies the full link with a one-time pairing code. After upgrading from the old remote access settings, the connection stays off until you enable it and scan again.
- **Keep the computer awake while tasks run** (#1730): turn it on in Settings → General and the computer will not sleep while a task is running; the display can still turn off. Off by default.
- **Manage scheduled tasks in conversations** (#1690): use `/schedule` or ask the model to create, edit, pause or delete scheduled tasks and review their runs. Task cards appear in the conversation, and scheduled sessions carry a clock mark in the sidebar.
- **Edit and resend a stopped prompt** (#1700, #1733): a message that was stopped before it got a reply can be edited and sent again, with the `/` and `@` menus available in the editor.
- **Providers and models**: an OpenRouter preset (#1682); a per-provider network proxy for custom providers — follow global, direct or manual (#1683); **Refresh model list** for official Claude, ChatGPT and Grok accounts (#1717); DeepSeek defaults to Flash with a 1M context, leaving saved mappings unchanged (#1695); a standalone DeepSeek search backend for WebSearch that works with any model (#1657); the lean profile can use the general-purpose and Explore sub-agents, WebSearch/WebFetch and the task list (#1716).

## Fixes

- **Agent Teams** (#1694, #1701, #1666, #1723, #1659): teams no longer get stuck while finishing; a team that failed to launch can be cancelled, an interrupted team can be ended, and a team ended before finishing shows Ended; follow-up messages to members no longer leave them waiting; task owners are shown consistently; sub-agents and members spawned from non-Claude sessions such as DeepSeek keep the current model; ordinary sessions stop polling for a team workbench that does not exist.
- **Long-session scrolling** (#1670, #1711): the scroll position survives history reconciliation, and switching tabs returns you to where you were reading.
- **Images** (#1661, #1664, #1714, #1705): the image viewer moves across every image in the session and supports download and zoom; official DeepSeek requests over 40 MiB upload images through the Files API instead of failing with 413; requests with more than 20 images keep every image within 2000px; a session no longer stays busy after a large-image turn.
- **Scheduled tasks and usage** (#1697): the first message after enabling scheduled tasks no longer fails with 400; output tokens are no longer under-counted on the Token usage page, so lifetime totals grow after upgrading — the new figures are the corrected ones.
- **Context** (#1687, #1734): the context ring and `/context` use the provider's fallback window, and switching back to a session tab reuses the context usage already computed.
- **Other desktop fixes**: a new-session draft can open the workspace before its first message (#1672); MCP servers that start late reconnect in running sessions, and updated provider credentials apply from the next turn (#1641); the retry banner expands and copies redacted diagnostics (#1667); renderer crash notices include the exit code and a restart action, and automatic reload is restored after stable running (#1721); third-party refusals name the selected model (#1658); a permission change on a cold session is no longer overwritten by a concurrent start (#1713); provider ordering, the update-config skill and compaction broken by empty Responses heartbeats are fixed (#1643).
- **Feishu** (#1655, #1722): connects through the desktop proxy, and logs and diagnostics exports no longer include the app_secret.

## Other

- **Composer toolbar** (#1654): the toolbar stays on one row, and the Agent profile (standard / lean) moved into the **+** menu.
- **Trace directory** (#1691): `CC_HAHA_TRACE_DIR` stores traces in a separate directory. Thanks to @gansuddd.
