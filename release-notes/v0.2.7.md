# Claude Code Haha v0.2.7

This release focuses on **Project Memory, a project-based session sidebar, plugin hot reload, chat input and desktop stability**.

Compared with `v0.2.6`, this release moves the desktop app from "you can see more capabilities" to "you can keep using them": Memory becomes a project-tree resource panel; the sidebar organizes sessions by project and persists preferences; plugin enable/disable, Skills and slash command lists hot reload; the chat composer supports drag-and-drop attachments and more readable math rendering; and a batch of everyday issues with scrolling, copying, attachments, zoom, startup diagnostics and IM completion state are fixed.

## Highlight

- **Project Memory becomes a project tree**: Memory in Settings is upgraded from a scattered list to a project-first file tree, with real path recovery, project search and Markdown preview navigation, and memory activity in chat uses one compact visual language.
- **Project-based session sidebar**: the desktop sidebar now groups sessions by project root, worktree sessions are merged under their source project, and preferences such as project order, hiding and pinning persist and sync between desktop and H5.
- **Plugin and Skills hot reload**: after enabling or disabling a plugin on desktop, the current session, empty sessions and `/api/skills` see the plugin's slash commands / skills sooner, without restarting the chat or the desktop app.
- **Better chat input and reading**: the desktop composer supports drag-and-drop attachments, Markdown rendering supports common math formulas, and scrolling and rendering costs for long and formula-heavy chats are further reduced.
- **Desktop fundamentals polished**: added a Settings UI Zoom slider unified with keyboard shortcuts; pure white theme by default; fixed copy feedback, empty session layout, crowded tab bar, H5 scrolling, large attachment payloads and startup white-screen diagnostics.
- **More reliable IM streaming cards**: Feishu / DingTalk card updates gain a completion fallback, so a card no longer stays in "typing" or blocks completion after the streamed text has finished.

## Main updates

- Project Memory adds a server API, desktop store, Settings page, chat memory activity card, and `/memory` / `/context` navigation entries.
- Memory project paths are recovered from the current cwd, session metadata and the real filesystem first, reducing projects with Chinese characters, spaces or legacy memory-only projects showing as dashes or garbled text.
- The Memory settings page uses project-tree navigation and removes manual memory file creation and mistakenly added project actions, focusing on browsing, searching, editing and previewing existing memory.
- The desktop sidebar groups by project root so worktree sessions are not scattered across multiple paths; project order, hiding, pinning and organization preferences persist in cc-haha's own configuration and are H5-compatible.
- Added an Open Project entry that opens the current session workDir in Finder or a detected local IDE, using the local app icon; packaged icon URLs are also correctly routed through the desktop sidecar.
- General Settings adds a UI Zoom control that shares one zoom state with the `Command +`, `Command -` and `Command 0` shortcuts.
- Thinking behavior for DeepSeek and similar providers now follows the global Thinking setting, and fixed reasoning-before-text streaming events causing a gap in the desktop status display.
- Enabling or disabling plugins refreshes the server's and the active CLI's settings / plugin cache, keeping new-session slash commands, empty-session skills and current-session plugin commands consistent.
- Desktop attachment selection in Tauri now sends local paths, preventing multiple or large files from being inlined as data URLs and inflating WebSocket / renderer payloads.
- The desktop composer supports adding attachments by dragging files from the system, reusing the existing path-only attachment pipeline instead of introducing a separate large-payload path for drag-and-drop.
- Markdown rendering supports common LaTeX math formulas, with lower KaTeX rendering and DOM costs for long formula-heavy chats.

## Fixes

- Fixed missing desktop confirm / alert permissions that stalled Superpowers plan confirmation or browser confirmation flows.
- Fixed new sessions created from external IM, scheduled tasks or other entry points not appearing until the desktop app was restarted.
- Fixed reused chat text selections sometimes being treated as file attachments.
- Fixed the composer's slash / @ file popovers being clipped after drag-and-drop attachment support was added.
- Fixed scrolling issues: restored chats auto-jumping to the latest message, tapping the latest message on H5 exposing blank space, and the transcript not scrolling to the new turn after sending a message.
- Fixed long chats mixing Markdown, math, code blocks and tool output leaving blank areas in the fixed-height virtual list.
- Fixed high rendering cost when switching long desktop sessions, while avoiding hidden sessions disconnecting a running CLI.
- Fixed inconsistent success across some desktop copy entry points caused by calling `navigator.clipboard` directly, and added toast feedback for copying H5 URLs, QR links, workspace paths and similar.
- Fixed old caches possibly overwriting desktop preferences when Settings writes and plugin state writes share `~/.claude/settings.json`.
- Fixed inconsistencies between Skills, Plugins and MCP resource discovery in Settings and the runtime, including linked skills, plugin skills and MCP from merged sources.
- Fixed packaged Open Project icons being blocked by CSP or relative URLs, and stale macOS command shims making uninstalled IDEs still appear.
- Fixed inconsistent contrast and visual style of Activity, Memory activity, Goal UI and the Zoom slider in white / dark themes.
- Fixed only a white screen remaining when startup fails before React mounts; an HTML-level watchdog now shows copyable diagnostic information.
- Fixed the lack of a cc-haha-specific destination for legacy provider configuration migration; migration imports into `~/.claude/cc-haha` and does not delete the original shared configuration.
- Fixed overly broad plugin marketplace / cache cleanup paths, avoiding automatic deletion of user paths outside the managed cache directory.
- Fixed Feishu / DingTalk streaming card update timeouts where text had been flushed but the final state never finished.
- Fixed common math formulas in model output only showing as raw LaTeX, while avoiding excessive chat rendering cost for formula-heavy content.

## Other notes
