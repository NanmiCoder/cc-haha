# Claude Code Haha v0.1.8

This release focuses on desktop Slash Commands, the Provider configuration experience and session stability.

Compared with `v0.1.7`, it adds visual inspection for `/status`, `/cost`, `/context` and similar commands on desktop, lets terminal workflows live inside the desktop app as standalone tabs, and fixes provider runtime drift, rewind targeting the wrong turn, and sessions getting stuck after the CLI exits unexpectedly.

## Main updates

- Improved the desktop Slash Command panel: `/status`, `/cost` and `/context` now show session status, usage and context information inside the desktop app instead of relying only on terminal text output.
- Desktop Slash Command behavior is closer to the CLI: local handling and boundary messages for `/help`, `/clear`, `/compact`, `/plugin` and others, and `Esc` closes the command panel.
- The terminal is now a desktop tab workflow: open and keep multiple terminal tabs in the tab bar, and the terminal in settings can open a standalone terminal tab directly.
- Improved Provider configuration: the settings page adds an API Key entry, explanatory text, show/hide key logic and local provider guidance, plus new presets for Jiekou AI, Shengsuan Cloud, LM Studio, Ollama and others.
- The Kimi preset now uses the coding endpoint, and the FAQ adds troubleshooting for common Kimi / custom provider authentication problems.
- When the desktop local service fails to start, the recent server stdout/stderr diagnostic log is shown and can be copied in one click, making sidecar or environment startup problems easier to locate.

## Fixes

- Fixed desktop sessions using a third-party provider sometimes falling back to old settings or wrong model capabilities; the session runtime now reliably uses the currently active provider, model and capability configuration.
- Fixed misdetection of thinking / adaptive thinking capabilities for third-party Anthropic-compatible endpoints, reducing request failures caused by incompatible model capabilities.
- Fixed desktop rewind sometimes rolling back to the wrong turn due to hidden messages or misaligned visible indexes; it now locates the target precisely by user message ID and verifies the original content.
- Fixed desktop turns sometimes staying "in progress" for a long time after the CLI exited unexpectedly during a session; abnormal exits now correctly end the current message state.
- Fixed subagent tool activity being incorrectly flattened in the desktop chat history; subagent tool calls and results stay nested.
- Fixed unreliable ripgrep path detection, so Bun virtual paths or non-executable paths are no longer mistaken for a usable `rg`, with a clearer error when it is unavailable.
- Fixed missing timeout protection on Feishu adapter HTTP requests, so slow external APIs no longer block bot processing for long periods.
- Fixed argument boundary handling for `/clear` and other Slash Commands, avoiding misparsing or wrongly clearing session state.
- Fixed the missing context percentage in the desktop inspector and `/context` queries waiting a long time in some runtimes, and improved model selector contrast in dark mode.

## Other notes

- The README and docs add sponsor and partner information, reference project notes, and troubleshooting for custom Provider / Kimi authentication errors.
- Release notes for earlier versions were completed and polished, making it easier to review history from GitHub Releases.
- The local macOS Apple Silicon test packaging script improves signing and sidecar verification, raising the launch success rate of local build artifacts; the official GitHub Actions release flow is unchanged.
- The GitHub Release body still comes from `release-notes/v0.1.8.md`, so the Markdown no longer has to be copied by hand.

## Installation

### macOS

If the app reports "is damaged" or "cannot verify the developer" on first launch, run:

```bash
xattr -cr /Applications/Claude\ Code\ Haha.app
```
