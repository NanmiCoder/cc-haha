# Claude Code Haha v0.7.4

本次首要修复 **Windows 上新建或恢复会话时反复弹出的黑色终端窗口**，并把 **Agents、工作流和斜杠命令提到 + 菜单一级**；同时修复 **Linux 包终端打不开**、**输入框上方浮层被裁**、**消息选中菜单跨会话串用** 等问题。

## 紧急修复

- **Windows 新建或恢复会话时反复弹出黑色终端窗口**（#1593，#1583）：根因是桌面 sidecar 被打包成了 GUI 子系统，它自己和它拉起的控制台子进程（例如每次启动 CLI 都会跑的机器码探测）因此各开一个可见窗口。v0.7.3 只处理了其中一条路径，本次把 sidecar 恢复成控制台程序，并在构建时检查子系统类型，避免再次回退。

## 核心改进

- **+ 菜单一级直达 Agents、工作流和斜杠命令**（#1601，#1597）：运行一个 Agent 或工作流不再需要先展开「更多工具」，一次悬停或点击就能到；「更多工具」这一行已移除，手机底部面板同样少一级。

## 修复

- **Linux 包的终端面板**（#1602，#1591）：此前的 Linux 包没有带上 node-pty 的原生模块，终端面板一律报「Failed to load native module: pty.node」，现在安装包会正确编译并校验该模块；同时把 Linux 模块改为按 glibc 2.28 编译，Ubuntu 20.04、Debian 11、RHEL 8 等环境也能正常使用终端。
- **输入框上方的浮层被页面裁掉**（#1598，#1587）：新会话时输入框居中、或把窗口压矮、或打开底部终端把输入框顶上去时，斜杠命令、@ 引用、+ 菜单和 /help 面板都会按上方剩余空间限高并在内部滚动，不再切掉顶部，也不会盖住 + 按钮。
- **文本选中菜单跨会话串用**（#1590）：当两个会话存在 id 与内容都相同的消息时（例如主会话和它的侧边对话），用快捷键切换会话后残留的「添加到对话 / 在侧边对话中提问」菜单不再生效，引用和侧边对话只作用于做选中的那个会话。
- **上游在流里报出的错误**（#1600，#1592）：中转站返回 200、却在 SSE 体里报 api_error / overloaded_error 时，现在按 API 重试预算重试（默认 10 次、间隔递增），不再是 2 秒内重试两次就结束；而上下文超长、额度不足、请求非法这类重发也没用的错误会直接报出来，不再重试。

## 其他

- **文档**（#1599）：中英文 README 增加「最全 API 中转站导航」推荐。

# Claude Code Haha v0.7.4

This release first fixes the **black console windows Windows users saw on every new or resumed session**, puts **agents, workflows and slash commands on the + menu's first level**, and repairs the **Linux terminal panel**, **clipped composer popovers**, **message selections leaking across sessions** and more.

## Critical fix

- **Black console windows on every new or resumed session on Windows** (#1593, #1583): the desktop sidecar was packaged as a GUI-subsystem binary, so it and every console child it spawned (such as the machine-id probe that runs at each CLI start) opened a visible window. v0.7.3 only covered one of those paths; the sidecar is a console program again, and the build now checks the subsystem so it cannot regress.

## Highlights

- **Agents, workflows and slash commands on the + menu's first level** (#1601, #1597): running an agent or a workflow no longer needs the More tools submenu — one hover or click reaches it. The More tools row is gone, and the phone sheet loses the extra level too.

## Fixes

- **Terminal panel in Linux packages** (#1602, #1591): Linux packages shipped without node-pty's native module, so the terminal panel failed with "Failed to load native module: pty.node". Packages now compile and verify that module, and the Linux build targets glibc 2.28 so Ubuntu 20.04, Debian 11 and RHEL 8 can use the terminal as well.
- **Composer popovers clipped by the page** (#1598, #1587): with the composer centred on a new session, in a short window, or pushed up by the bottom terminal, the slash menu, @ references, the + menu and the /help panel are now capped at the room above them and scroll inside; the top is no longer cut off and the + button stays uncovered.
- **Text-selection menu leaking across sessions** (#1590): when two sessions hold a message with the same id and content (a chat and its side chat, for example), the Add to chat / Ask in side chat menu no longer survives a keyboard session switch, and references and side chats only apply to the session where the selection was made.
- **Upstream errors reported inside the stream** (#1600, #1592): when a relay answers 200 but reports api_error / overloaded_error in the SSE body, the request is now retried on the API budget (10 attempts by default, with growing delays) instead of giving up after two retries in two seconds. Errors that a resend cannot fix — context length exceeded, insufficient quota, an invalid prompt — are surfaced immediately.

## Other

- **Docs** (#1599): the bilingual READMEs recommend Zuiquan API Directory.
